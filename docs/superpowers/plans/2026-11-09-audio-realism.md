# 音のリアリティ向上(第 3 ラウンド)実装計画 — 2026-11-09

ユーザーの実機所見は 2 段で来た:

1. 第 2 ラウンド(CC0 素材 + 多層合成への作り替え、TestFlight 2.0 (21))を聞いて
   なお「音がやっぱ全体的にチープ」。
2. 具体的な指摘:「**安っぽいのは特に銃の発射音。ピンピンピンピンみたいな。弱い**」
   「**もっと重厚な SF の音**が欲しい」「**音はリアルにしてほしい。映像は
   ちょっとドット(ピクセル画)だけど、音はもうリアルでいい**」。

つまり、音を映像のドット感に合わせる必要は一切なく、**音響は映画的な
リアルさ・重厚さで作る**のが正解。優先順位は次のとおりに変更する:

- **最優先: 武器音**(パルス / 重粒子砲 / 砲台)。ここが仕上がらないうちは
  環境側を先に固めない。
- 継続: 環境音の実録化とミキシング/マスタリング(ただし工数の重心は武器音)。

ゲームの数値・判定・発火タイミング(どの出来事でどのメソッドが呼ばれるか)は
変えない。変えるのは素材・音色・ミックスだけ。

5 kHz 以上 RMS の dB 差で、小さいほどエネルギーが高域に集中 = 甲高く薄い)。

### 分類(台帳との突き合わせ)

- **合成ザップ系**(Kenney の sci-fi-sounds / digital-audio / interface 由来。
  安さの主因): pulse_0/1/2 (laserSmall)、laser_large (laserLarge)、
  pickup_charge/heal/ration (powerUp)、warn_error (error)、confirm
  (confirmation)、tick、ladder_1 (tick)、thruster、explosion_crunch、
  explosion_low、engine_loop。
- **実録・打撃系**(質感があり、残す候補): hit_0/1、down_impact、hurt_impact、
  land_0、footstep_0〜4、mining_0/1、crash_metal、ladder_0、switch、cache、
  eat_0/1、jingle_milestone/record、rest。

### 安く聞こえる主因の特定

1. **パルス = laserSmall の純合成ザップ**。エネルギーが 5 kHz 以上に集中し
   (bright 2.3〜3.9)、低域の胴体が存在しない。「ピンピン」の正体はこれ。
   砲台の laserLarge、取得の powerUp も同系統で、鳴るたびに「ゲーム素材」の
   印象を更新し続ける。
2. **loudness が無統制**。第 2 ラウンドの素材加工はピーク正規化だけで、
   RMS はカテゴリ間で最大 25 dB、同一音のバリエーション間でも 5.8 dB
   (パルス)/ 16 dB(梯子)ばらつく。足音(-32)が聞こえず、confirm / rest
   (-14)が突出するなど、ミックスとして成立していない。素材が良くても
   バランスが取れていなければ安く聞こえる。
3. **環境音が合成主体**。ドローンは合成パッド、重ねている engine_loop も
   合成音で、しかも最大 0.2 の脇役。プレイ時間の大半を占める層が合成音の
   ままなので、全体の印象がここで決まる。
4. **空間処理が単一系統**。リバーブは開放度連動の 1 系統だけで、UI の小音も
   砲の轟きも同じ残響に送られる。マスターのコンプレッサも ratio 4 /
   threshold -18 dB では天井(リミッター)として機能していない。

## 方針

### 武器音の作り直し(最優先)

共通の考え方: **実録を芯に、低域で重みを付け、エネルギー感は暗く抑える**。
甲高い帯域(5 kHz 以上)は EQ で切り、「SF らしさ」は帯電ノイズと残響の
尾で出す。

- **パルス(6 発/秒)**: laserSmall は廃止。
  - 芯: 実録の銃声/機械動作音(CC0/PD)を短く切り、ローパスで暗くする。
  - 胴体: 正弦波のサブサンプ(120→38 Hz、約 0.12 秒)で腹に響かせる。
  - エネルギー層: バンドパスノイズ + 細い鋸波の落下を **3 kHz 以下に
    ハイカット**して重ねる(帯電感は出すが甲高くしない)。
  - 破裂: ローパス 1.2 kHz 程度の短いノイズバースト。
  - 尾は 0.16 秒以内に締め、連射で破綻させない。バリエーションは実録
    3 種のローテーション + レート/ゲインの決定論ばらし(従来の仕組み)。
- **重粒子砲**: 映画の大型エネルギー兵器級に格上げ。
  - 溜め: 既存の唸りに帯電ノイズの低域化とサブの太さを足す。
  - 発射: 既存のサブ + ノイズ + explosionLow に、**実録の爆発/大砲系**を
    芯として追加。残響はホール系へ厚く送る。
- **砲台(敵)**: パルスと同じ実録の芯を使い「同じ世界の武器」の家族感を
  持たせつつ、レートを上げて細く、サブを浅くし、プレイヤーの武器より
  軽く・遠く聞こえる差を付ける。laserLarge は廃止。

### ミキシング / マスタリング

- **loudness 目標(素材側 RMS の目標帯)** をカテゴリごとに決め、素材の
  再正規化と engine の gain を実測ベースで揃える:
  - 環境ループ: -26 dB 前後(鳴り続けても疲れない帯域)
  - 足音・梯子などの小さい動作音: -24 dB 前後
  - UI・合図: -22 dB 前後
  - 取得・開封: -20 dB 前後
  - 命中・打撃・着地: -18 dB 前後
  - パルス(1 発): -15 dB 前後
  - 砲・爆発・ボス: -13〜-14 dB 前後
- **per-sound EQ**: playSample にローパス(ハイカット)の指定を持たせ、
  ザップ感の残る音・甲高い打撃は個別に切る。
- **リバーブ 2 系統**: 短い部屋系(room、固定 0.35 秒級)と長いホール系
  (hall、従来の開放度連動 0.15〜1.6 秒を格上げ)。UI・合図は room、
  砲・ボス・爆発と環境に近い音は hall。playSample / voice に送り先の
  指定を持たせ、既定は hall(従来互換)。
- **リミッター的な天井**: マスターのコンプレッサを threshold -8 dB /
  ratio 12 / attack 0.002 / release 0.24 程度に見直し、同時発音で
  クリップさせない。

### 環境音の実録化(武器音の後)

- 地区グループごとに実録ループを主役にする:
  - 機械・工業系(coldSteel / power / foundry / disposal): 実録の機械室・
    工場のルームトーン。
  - 標準(habitation): 静かな室内のルームトーン。
  - 水域(waterVoid): 水の洞窟・滴り・水辺の環境音。
  - 生体(biomech): 実録が薄い領域。有機的な環境音が取れなければ洞窟の
    風などの実録で代替し、合成ドローンを薄く残す(限界として明記する)。
- 合成ドローンは接着剤まで下げ(バイオームごとの gainDb を見直す)、
  実録ループのゲインを主役の帯域(0.5〜0.7 級)へ上げる。ループは素材側で
  クロスフェード化して継ぎ目を消す(engine_loop の前例と同じ手法)。

### 素材の入手と台帳

- 入手先はログイン不要の **CC0 / Public Domain のみ**: OpenGameArt.org
  (CC0 指定のものだけ、アイテムごとにライセンスを確認)、archive.org の
  CC0 / PD コレクション。freesound はログイン必須のため使わない。
  Kenney の実録系で実測上問題ないものは残す。
- 使った素材は全て `assets/audio/CREDITS.md` に記録する(ファイル名・
  入手元 URL・ライセンス・加工内容)。**台帳に無い素材は使わない。**
  既存の Kenney 素材を差し替える場合は、台帳の行も差し替え後の内容に
  更新する。
- 容量の目安: ループ素材は 1 件 200 KB 程度まで、音源総量 1.5 MB 以内
  (超える場合は報告に明記)。

## 実装時の裁定(2026-11-09 実装後に追記)

- **パルスの層構成は「実録の芯 + サブサンプ」の 2 層に絞った**。計画の
  エネルギー層(バンドパスノイズ + 鋸波)と破裂ノイズ層は入れていない。
  実録の芯(M45 の近距離テイク)自体に破裂と機構の帯電感が含まれており、
  合成層を足すと第 2 ラウンドの「合成っぽさ」が戻るため。SF らしさは
  サブの pitch 落下とホール送り(0.3)で出す。フォールバック(サンプル
  未ロード時)も甲高い音には戻さず、ローパスで暗くした鋸波の芯のみにした。
- **パルスの loudness 目標はブラスト(先頭 60 ms)基準で管理した**。実録の
  銃声はエネルギーが先頭約 40 ms に集中し、ファイル全体 RMS は尾の長さに
  引きずられて意味を持たないため。素材実測: ブラスト RMS -14.5/-14.7/-14.9
  (目標帯 -15 前後を達成、テイク間 ±0.2 dB)、全体 RMS -17.4〜-17.7、
  ピーク ≈ -0.4 dB。加工は compand で機構部の尾を持ち上げてから
  -1 dB でクリップ(素材側の Prepared マスタリングと同じ流儀)。
- **cannon_body(散弾銃の胴体)は RMS -20.4 で妥協した**(当初目標 -15.5)。
  ブラストのクレストが大きく、RMS を上げるには圧縮で芯を潰すしかなく、
  パンチが死ぬ。ピーク -0.4 の打撃感を優先し、全体の大きさは
  cannon_bang(-16.1、ホール厚送り)と合成サブ(FIRE_SUB_GAIN)が担う。
- **acompressor は使わなかった**。実測で全体をダッキングする挙動
  (RMS がむしろ下がる)を確認し、compand + numpy のゲイン/クリップに統一。
- **環境ループの disposal は機械系と共通**(amb_machine)。グループ分けは
  機械系(寒鋼/電力/廃棄)/精錬/居住/水域/生体の 5 ファイル。
- **engine gain は Task 4 で変更しなかった**。素材側の正規化だけで
  カテゴリ間の相対バランスが目標帯に入ったため。突出していた confirm /
  rest は素材側で -7.7 / -9 dB 下げた。
- 加工中に tick.ogg を一度破損させた(極短ファイルへの 2 パス再エンコードで
  vorbis の前置無音に食われた)。git から復元し、単一パスの ffmpeg
  フィルタで再加工した。以後、短尺素材は単一パスで処理する。

## 保留

- **聴感の最終判定は実機**。特に: パルスの重さと連射時の潰れ具合、
  サブサンプ層の効き(スマホのスピーカーでは低域が出ず、イヤホン前提の
  設計)、砲の実録レイヤーと合成サブのバランス、環境ループの継ぎ目と
  地区ごとの聞き分け、リミッター天井での同時発音の詰まり感。
- **生体系の環境音は代替のまま**。CC0 の実録で有機的な環境音が見つからず、
  空気のうねるアンビエント録音(ambient_04)を使った。専用素材が見つかれば
  差し替える。
- disposal は機械系とループ共通。地区別の専用化は未実施。
- frametime の静穏時再計測(+0.5 ms 基準の確定)。
- パルスのエネルギー層(帯電ノイズ)は裁定で見送った。実機で「SF らしさ」が
  足りなければ、3 kHz 以下に切った帯電層だけを薄く足す余地を残す。
