# 計画: 音系の全面見直し（監査と不足分の追加）

背景: v2.0 で重粒子砲の音（溜め・発射・破砕）とボス警告音を足したが、実機報告で「パルスの音がない」と判明した。ユーザー指示「音系を全部見直して作り込み、足りてないやつは全部足して」（2026-11-08）を受け、まず全イベントを監査し、不足分を既存エンジン（`src/audio/`）の流儀で全部足す。
ブランチ: `feat/audio-complete`
範囲: 音の追加とその発火結線だけ。ゲームの数値・判定・描画は変えない。

## 実装時の裁定

- **パルスの音の正体は「未実装」だった**： エンジンに発射音のメソッド自体が無く、`PulseGun.shotsFired` は検証用カウンタで main は読んでいなかった。結線漏れでも音量ゼロでもない。発射検出は `shotsFired` の差分で行い、エンジン側は発射インデックスで pitch をばらす（`pulseDetune`、黄金角の sin で ±4%）。間引きは保険として最小間隔 30ms をエンジンに置いた（通常の連射間隔 1/6 秒では効かない）。
- **撃破音は `onEnemyKilled` に集約**： パルス・ビームどちらの撃破でも同じ音になる。命中（非撃破）は命中判定の各所で `hit()` が false を返したときに鳴らす。ボス撃破は `onBossKilled` で専用の重い音に分けた。
- **復活音はエンジン側で 0.2 秒遅らせる**： 死亡と復活が同一フレームで起きるため、遅延なしだと死亡音と重なる。
- **ジャンプ音はノックバック中を除外**： 被弾の跳ね上がり（vy=-6）も「接地→空中＋vy<-5」を満たすため、`player.knocked` の間は鳴らさない。
- **着地の落下速度は前フレーム末の vy で近似**： 着地フレームでは moveBody が vy を 0 にするため、直前の空中 vy を使う（重力 1 フレーム分だけ小さく出る）。
- **梯子の検出は Player.onLadder と同じ述語を main で再現**（中心タイル＋足元タイル）。Player 側は変更していない。
- **自動摂取は結果オブジェクトの `ateRation` を拾うだけ**： stepSatiety の返り値を main が捨てていた。数値・仕様は無変更。
- **復活点更新音は「値が変わったときだけ」**： 箱の中にいる間は 6 フレームごとに代入されるため、変化検出なしだと鳴り続ける。
- **砲の弾回復の合図は差し引き方式**： graviton.update の前後で charges を比べ、増えたときだけ鳴らす。発射と回復が同じフレームだと相殺されて鳴らないが、誤報より欠落を取った。
- **有限バッファの BufferSource にも stop() を明示**（足音＝既存分を含む）： 鳴らし切り前提で stop を呼んでいなかった 5 箇所（足音・命中ノイズ・着地・梯子・摂取）を他と揃えた。音自体は変わらない（バッファ長以下で止める）。これにより「生成した一時ノードは全部 stop される」が計装で機械的に証明できるようになった。
- **敵弾の地形命中・ミュート切替・ズーム段変化には音を付けない**（監査表の判断どおり）。

## 保留

- **全ての新規音の聴感（音量・重さ・既存音とのバランス）はヘッドレスで判定できず、初期値のまま実機判定が前提**。調整は `src/audio/params.ts` の各節の定数だけで完結する。
- パルスの音量（0.16）は砲（発射サブ 0.9）との対比で置いた。実機で埋もれる／煩い場合は PULSE_GAIN と PULSE_SECONDS の調整が要る。
- 敵・砲台・ボスの音に距離減衰は付けていない（既存エンジンに位置音響の仕組みが無いため）。画面外に近い砲台の発射音も同じ音量で鳴る。実機で気になる場合は距離減衰の導入が次の打ち手。
- 飛行敵の追尾開始音は、複数の飛行敵が同時に追尾へ入ると重なって鳴る。頻度が実機で気になる場合はエンジン側の間引き（最小間隔）を足す。
- 梯子の段音・着地音は検証スクリプトの駆動範囲外（梯子のある場所まで連れて行く脚本が無い）で、結線はコード確認のみ。実機・実プレイでの確認が残る。
- ボスの出現・突進・激突・撃破音も同様に、ヘッドレスではボス戦まで駆動していないため結線のみ確認。実機判定に回す。
