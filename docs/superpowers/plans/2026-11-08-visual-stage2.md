# 計画: 見た目大幅改善 段階 2 — プレイヤーと歩行

設計書: `docs/superpowers/specs/2026-11-08-visual-overhaul-design.md`（ユーザー承認済み、2026-11-08）
ブランチ: `feat/visual-stage2`
範囲: 設計の段階 2 のみ。**プレイヤーの造形と歩行の作り直し**。地形（段階 1、完了）とビーム・演出（段階 3）は扱わない。

診断の要点（設計書より）: 歩容の振幅が 1px 未満に潰れて脚の線の切り替わり（痙攣）だけが残る／1 歩で体が約 2.1 タイル進むのに足の振り幅は 0.4 タイルで接地足が約 8 割滑る／脚が約 2px の線で下半身が背景に消える／胸の赤はパレット外で茶色に化けている。

## Task 2: 歩行の作り直し

- [ ] 足音は既存規則（位相の π 跨ぎ＝着地）と整合を保つ
- [ ] 検証： 歩行シーケンスの連続フレームで、痙攣と足裏の滑りが消えたことを目視確認する。位相と歩幅の関係をテストで固定する

## 実装時の裁定

- **歩容の純粋関数は `src/core/gait.ts` に新設**（Task 2）。位相の進み（`walkPhaseAdvance`）、1 足のプロファイル（`gaitFoot`）、体の上下（`gaitBodyOffset`）を純粋関数として Vitest で固定した。player（entities）と playerPose（render）の両方から参照するため、core に置いた（段階 1 の satiety と同じ流儀）。
- **歩幅は 1.0 タイル、接地期の割合は 0.55**（設計の 0.9〜1.1 の中央と、両足接地の時間を作るための 0.5 超）。足の前後振幅は「接地期の割合 × 歩幅」= 0.55 タイルで、接地足の対地速度がちょうど 0 になる値（テストで「体の前進量＋足の後方への流れ = 0」を固定）。
- **着地は位相の π の倍数に置いた**ため、足音の発火条件（`footstepCrossed` の π 跨ぎ）は無変更で整合する。params 側はコメントだけを実態（距離駆動）に合わせて更新した。
- **頭の基準位置を -2.08 → -2.04 タイルへ**（Task 2）。体の上下動を 0.06 に増やし頭を半分追随させると、頭頂が描画高さ 2.25 タイルの上限を超えるため。シルエットの当たり（物理ボディ 1.75 タイル）は不変。
- **上半身の揺れ（横揺れ・腕の反動・頭の安定化）は sin のまま**にした。地面に触れない部位には滑りの問題がなく、既存の対称性テスト（反動の符号反転など）もそのまま活きる。歩行の情報の主役は足のプロファイル側に寄せた。
- **脚の面化は四角形（limbQuad）で太もも・脛を描く方式**（Task 1）。幅は太もも 0.23→0.20、脛 0.19→0.15（設計の初期値 0.22 / 0.18 に相当）。前脚 = 太もも明段・脛中段、後脚 = 太もも中段・脛暗段とし、色はすべてパレット実在色（uniformLight #2a586f / uniform #16202b / uniformDark #0a121a を新設）。
- **胸の装甲は設計推奨 (a) を採用**： chest = 錆 #9a6d32（パレット 30 番）、chestLight = 金 #caa64a（31 番）。合わせて他の色も全てパレット実在色へ寄せた（face #c7d0ce、joint #51728d、visor #05090f、weapon #192633、indicator は胸の上で点滅する灯として #c7d0ce）。

## 保留

- 歩行の「気持ちよさ」（振幅 0.14 の足上げ、着地の沈み込み、前傾、コートの翻り）の最終判断は実機判定待ち。設計 §9 のとおり、実機で弱く感じれば振幅を増やす方向の調整が残る。
- 足音は歩幅 1 タイル化に伴い最高速で約 6 回/秒（従来約 2.9 回/秒）になった。着地と同期する仕様上は正しいが、実機で煩く感じれば音量・間引きの調整が要る。
- 胸の錆色（設計 §8-①）は初期値として採用したもので、実機判定で寒色の明段へ差し替える余地が残る。
- 梯子・空中・静止のポーズは現行踏襲（本段階の対象外）。
