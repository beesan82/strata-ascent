## 実装時の裁定

- **findLedge の候補行は高々 1 つ。** 手の範囲は「体上端 ≤ 縁の上面 ≤ 体上端 + 0.7」で、縁の上面は整数行なので `ceil(body.y)` だけを見る。落下の最大速度 25 タイル/秒(1 フレーム 0.42 タイル)でも窓 0.7 を 1 フレームで跨げないため、取りこぼしはない。
- **壁面との隙間は 0.1 タイルまで許す。** `moveBody` の 1/16 刻み探索が壁の手前に最大 1/16 の隙間を残すため、側面から 0.1 以内に固体列があれば「接している」とみなす。
- **スナップ位置の重なりは findLedge の中で弾く。** 縁の条件を満たしても、掴まり位置(体上端 = 縁の上面 + 0.25、側面が壁面に接する)に置いた体が固体と重なるなら null。よじ登り先の重なりは設計どおり登る時に `bodyOverlapsSolid` で見る。
- **掴まりは入力の向きだけで試す(両側同時には試さない)。** 右入力なら右、左入力なら左、入力が無ければ水平速度の符号(moveBody で潰れる前の値)。左右同時押しは入力なし扱い。設計の「壁方向へ移動中、または押し付けている」の素直な読みで、両側を試すのは縁が両側にある縦穴で向きが曖昧になるため採らなかった。
- **ノックバック中・梯子上では掴まらない。** 被弾で離した直後に壁へ跳ね返って再掴まりする見た目を避ける。梯子は梯子の操作を優先する。
- **よじ登りのジャンプは押下エッジ。** ジャンプを押したまま掴まっても即座には登らない(上入力は長押しで登る)。ジャンプで登った直後もジャンプが押されたままなら、既存の「接地中にジャンプ押下で跳ぶ」規則どおり次フレームで跳ぶ(接地の扱いを変えていない)。
- **よじ登り後は `onGround = true` を立てて `ledge` を外す。** 翌フレームの重力と衝突解決で床に揃うので、コヨーテ・バッファは通常どおり働く。
- **掴まり中の武器抑止は main で行う。** `pulseGun` には `pulseHeld && !hanging`、`graviton` には `cancelCharge()` のうえ `fireHeld && !hanging` を渡す。Player は武器を知らないので、Player 側に武器の状態は置かない。
- **満腹度の静止扱い**は `stepSatiety` の `still` に `onGround || hanging` を OR するだけ。眺望の `still` は接地が前提なので触らない。
- **描画は `calculatePlayerPose` の末尾に省略可能引数 `hanging` を足した。** 掴まり中は歩行・照準の計算に乗らず固定ポーズを返す。`drawPlayer` と `poseMuzzleWorld` に同じ引数を通し、描画パス・色数は増えていない。ポーズ原点(足元)から縁の上面までは 1.75 + 0.25 = 2.0 タイルで、両手をそこへ置き、頭頂は縁より下に収めた(物理の沈み量 `LEDGE_HANG_DEPTH` と対応)。
- **音は着地音に相乗りした。** `audio.land(fallSpeed)` はゲインを落下速度から決めるので、鳴る最小の速度 `LAND_MIN_VY`(ゲイン 0.12)を渡す。新しい音・サンプルは足していない。よじ登り後の接地では `prevFallVy` が 0 なので着地音は鳴らない。
- **ハプティクスは main の遷移検出(`prevHanging` → `player.ledge !== null`)で発火。** 既存の接地・落下の遷移検出と同じ形。
- `PlayerInput` の拡張は不要だった(上・下・左右・ジャンプで足りる)。

## 保留

- 壁蹴り・壁ずり(ウォールスライド)は次の候補。掴まりの判定(`findLedge`)と状態機械(`ledge`)の上に足せる形になっている。
- 掴まり中にスティック照準で向きを変える操作は無効にした(壁の側を向いたまま)。掴まり中に反対側を狙う要望が出たら、ポーズの腕と合わせて再検討する。
- 縁の上が 1 タイルしか空いていない(登れない)縁にも掴まれる。設計どおり登る操作だけが無効になるが、「登れない縁に掴まる」場面が頻発するなら、成立判定の時点で登り先を見る案がある。
- 掴まった瞬間の着地音は最小ゲイン固定。専用の音(手が縁にかかる短い音)は新規サンプルになるため見送った。
- 掴まり中のポーズは静止(呼吸の bob のみ)。登る・離す瞬間の中間ポーズ(1〜2 フレームのよじ登りアニメ)は足していない。
