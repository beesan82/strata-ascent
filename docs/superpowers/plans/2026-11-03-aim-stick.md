# 実装計画: エイム専用スティック

設計書: `docs/superpowers/specs/2026-11-03-aim-stick-design.md`(2026-11-03 ユーザー承認済み)

## Task 1: Input の照準入口(テスト先行)

- `src/core/input.ts`: `touchAimX/touchAimY/touchAimActive` と `setTouchAim(x, y)` /
  `clearTouchAim()` を追加。
- `src/core/input.test.ts`: 設定で有効化、クリアで無効化を固定。
- `src/core/touch.ts` に純粋関数 `aimStickState(dx, dy)`(デッドゾーン 18px、単位ベクトル化)を
  置き、`touch.test.ts` にケースを追加。

## Task 2: ツインスティック化

- `touch.ts`: スティック生成を共通化し、左半分レイヤー=移動、右半分レイヤー=エイムにする。
  エイム側は倒している間 `input.setTouchAim` + 発射 ON、離すとクリア + 発射 OFF。
  発射は砲ボタンとの OR で仲介する(片方を離しても他方が押していれば維持)。
- `index.html`: スティックの土台/ノブを id から class に変え(2 組使うため)、
  レイヤーの左右分割 CSS を追加。
- README のタッチ操作の行を更新。

## Task 3: main.ts の配線

- マウス未使用時、タッチ照準が有効なら合成マウス位置と viewState の aimX/aimY を
  照準ベクトルから作る。無効なら現行の水平フォールバック。

## Task 4: 総合検証と記録

- `npm test` 全件、tsc、build。
- エミュレーションで 2 本指(移動+右上エイム)を再現し、斜め撃ちを確認。
- PC 開始地点は差分 0。本計画の末尾に裁定・計測・保留を追記する。

## 実装時の裁定

- 照準の合成マウス位置は現行の水平フォールバックと同方式(中心 + 方向 × 画面の 1/4)。
  レンダラのエイム角はプレイヤー表示位置からの atan2 なので、中心からずれる分だけ
  わずかな誤差が出るが、現行方式と同程度として許容した。
- 移動スティックは「画面のどこでも」から「左半分」に変わる(ツインスティックの必然)。
  エイムと移動を別 pointerId で独立に受ける。

## 計測

- テスト 474 件(新規 3 件)全通過、`npx tsc --noEmit` 通過、`npm run build` 成功。
- 描画パスには触っていない(main.ts の照準合成は入力値の選択のみ)ため frametime 計測は省略。
- PC 開始地点(`--freeze=true`)は差分 0。
- タッチエミュレーション(CDP の 2 本指同時タッチ): 左右両方のスティックが同時に出て、
  右上エイムでライトコーンが右上を向き、発射のグローが出ることを撮影確認した。

## 保留

- 実機でのツインスティックの操作感(特に右半分のどこからがエイムになるか)はユーザー確認待ち。
- エイム中の自動発射は仕様どおり。撃ち続けの可否は実機フィードバックで判断する。
