# 計画: 掘削縁の熱表現の強化（溶け・赤熱・ケレン味）

背景: 見た目改善 段階 3（PR #45）で掘削縁の熱色（錆＋金、6 秒）を入れたが、ユーザーから「抉れた地形が熱を帯びて溶けたり赤くなったりするようなケレン味が欲しい」と追加要望（2026-11-08）。段階 3 の設計要素（掘削縁の残光）の強化として扱う。
ブランチ: `feat/hot-melt-edges`
範囲: 掘削縁の熱表現だけ。砲の数値・判定、地形生成、他要素は変えない。

## Task 1: 冷却段階を持つ熱表現

- [ ] 掘削直後からの経過で段階的に冷える表現にする。初期値の目安： 直後（〜1.5 秒）は白金の芯＋赤い縁で最も熱く、次段（〜4 秒）は赤〜錆、末段（〜8 秒）は暗い錆が残って消える。段階の切り替えは ChunkBaker の再焼き込みに相乗りさせ、毎フレームの描画コストは増やさない
- [ ] 色は 32 色量子化で意図どおり出るパレット実在色から選び、量子化後の実効色を最近傍計算で確認する（赤はパレット外の色が茶色に化けた前例があるため特に注意）
- [ ] 検証： クレーターの時系列スクリーンショット（発射直後／1.5 秒／4 秒／8 秒／冷却後）で段階の遷移を確認する

## Task 2: 溶けの表現

- [ ] 熱い段階では、掘削縁から下向きに熱色が 1 タイルほど垂れる「溶けだれ」を決定論で付ける（長さはハッシュで決める。地形生成には影響させない）
- [ ] 熱い段階の縁はわずかに太くし、冷えるにつれて通常の縁へ戻す
- [ ] 検証： 時系列スクリーンショットで、溶けだれが熱い段階だけに出て冷却後に残らないことを確認する

## Task 3: 仕上げ

- [ ] 標準 3 場面（発射なし）は差分 0 画素を維持する

## 実装時の裁定

- **冷却段階は純粋関数 `heatStageAt`（`src/render/hotedge.ts`）で固定**（Task 1）。境界は計画の目安どおり 1.5 秒／4 秒／8 秒で、総持続は従来の 6 秒から 8 秒へ延びた。段階の見た目は `HEAT_LOOKS`（層の配列）に集約し、全色のパレット所属・深さの単調性・段階ごとの総深さ（0.36 → 0.27 → 0.22 タイル）をテストで固定した。
- **「赤」は色相では出せないことを数値で確定し、明度勾配で代替した**：32 色パレットに赤系は存在せず（暖色は暗褐 #3d2618／褐 #5a3a24／錆 #9a6d32／金 #caa64a のみ）、純粋な赤（#ff2a1a、#e0301e、#ff4030 等）は量子化の最近傍計算で全て錆 #9a6d32 に落ちる（暗所では褐 #5a3a24）。このため段階構成は、白熱＝白 #c7d0ce の芯＋金＋錆の外帯、赤熱〜錆＝錆の帯＋金の際線、末段＝暗い錆 #5a3a24 とし、「赤熱らしさ」は色相でなく最も熱い色の梯子（白→金→錆→暗褐）と太さ・溶けだれで作った。実画面の画素サンプリングでも段階ごとの色構成の遷移を確認済み（クレーター拡大の最近傍集計：直後は白 1020px・金 297px、4 秒では白 0・金 18px・錆 585px、末段は暗褐が支配的）。
- **段階管理は ChunkBaker の「加熱時刻＋焼き込み済み段階」方式**（Task 1）：`markHot` は期限でなく加熱時刻を刻み（再射撃は時計を戻して白熱からやり直す）、`advanceHeat`（旧 `expireHot` を改称）が段階の食い違いを検出したチャンクだけを 1 回ずつ無効化する。bake 自身も実際に描いた段階を記録するため、再焼き込みが遅れて段階を跨いでも自己修復する。毎フレームの再焼き込みは従来どおり無し。
- **溶けだれは純粋関数 `meltDrips` で固定**（Task 2）：源は掘削縁そのもの（天井面 s は下の空気セルへ垂らし、床面 n と壁面 e/w は固体の面を伝わせて自タイル内に収める）。上のチャンクの最下行の s 面も源に含め、逆に自チャンク最下行の s 面からのだれは下のチャンク側の焼き込みが描くことで、チャンク境界を跨いでも欠けない。部分再焼き込みとの一致のため、範囲判定は源の面でなく、だれの矩形と span の重なりで行う。本数は段階 0 で縁あたり 0〜2 本（ロール 0.4 未満は無し）、段階 1 では疎らに（0.62 未満は無し）・短く（最大 0.45 タイル）、段階 2 以降は出ない。幅 0.07〜0.13 タイル、先端には 2px の滴（段階 0 は白、段階 1 は金）。
- 砲の数値・判定（BORE 定数、`beamHit`、ダメージ）と地形生成には一切触っていない（標準 3 場面の差分 0 画素と、冷却後＝発射 9.5 秒後の差分 0 画素で担保）。

## 保留

- 「赤熱」の赤さはパレットの制約で錆＋金の明度勾配による近似が上限（上記裁定）。実機の小画面で「溶けて赤熱している」ケレン味として読めるかは実機判定待ち。段階の境界（1.5／4 秒）、帯の太さ・濃さ、だれの頻度と長さはすべて初期値で、実機の感想で調整する想定。
- 溶けだれは壁面（e/w）では自タイル内に収まる長さに制限したため、長い壁面を伝い落ちる表現にはなっていない。物足りなければタイルを跨ぐだれが候補だが、部分再焼き込みとの画素一致の担保が難しくなる。
- bake の厳密な前後差は代理計測（冷却窓の render max）までで、チャンク単位の焼き込み時間そのものは測っていない（段階 1 と同じ制約）。
