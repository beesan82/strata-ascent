# 実装メモ: 2.6 の実機フィードバック修正（2.7）（2026-11-09）

ブランチ: `fix/feedback-2-7`（起点 origin/master）

## 直したもの

1. **アイテムボックスが画面に入りきらない**（横画面のスマホは縦が短く、状態セクション追加で溢れた）
   - `#itembox` に `max-height: calc(100dvh - 20px - safe-area)` と `overflow-y: auto` を付け、パネル内でスクロールさせる。ラベルの余白も少し詰めた。横画面 844×390 で、パネルが画面内に収まり内部スクロールすることを確認した。

2. **視点を変えても前しか向かず、弾が背中から出る**
   - 原因: 体の向き（facing）の反転条件が「タッチ照準の横成分 0.3 以上」だけだった。背中側への斜め照準（横成分が小さい）や保持照準では体が前を向いたままになり、腕と銃口だけが照準どおり背中側へ回るため、発射が背中から出て見えた。
   - 修正: 向きは照準に一致させる。タッチ照準・保持照準・砲モードのマウス照準の横成分が 0.05 以上あればその側を向く。真上/真下の照準と崖つかみ中は向きを保つ。

3. **ボス HP バー（広間番人）の表示条件**
   - 広間のあるセルに入っただけで常時表示になっていた。プレイヤーが大広間の中にいる間だけ表示するよう絞った。
