# 実装計画: 浮動バーチャルスティック

設計書: `docs/superpowers/specs/2026-11-03-virtual-stick-design.md`(2026-11-03 ユーザー承認済み)

## Task 1: stickKeys(テスト先行)

- `src/core/touch.ts` に純粋関数 `stickKeys(dx, dy)` を置く(閾値: 横 14px、縦 18px)。
- `src/core/touch.test.ts`: 停止/左右/上下/斜め/デッドゾーン内を固定する。
- 検証: `npm test`、`npx tsc --noEmit`。

## Task 2: スティック UI とボタンの整理

- `touch.ts` の `installTouchControls` を作り替える:
  - 全画面レイヤー + 土台円 + ノブで浮動スティック(pointer capture、1 本の指だけ)。
  - ボタンは右下の 跳(Space)・砲(KeyF)だけにする(← → ↑ ↓ は撤去)。
- `index.html` にスティック用 CSS を追加し、右クラスタの幅を 2 ボタン分に直す。
- `src/main.ts` の配線は不変(`installTouchControls(input)`)。
- README のタッチ操作の行をスティック方式に書き換える。
- 検証: tsc、build。

## Task 3: 総合検証と記録

- `npm test` 全件、tsc、build。
- エミュレーション: スティック表示の撮影 + ドラッグ長押しでプレイヤーが歩く確認。
- PC 開始地点は差分 0。
- 本計画の末尾に裁定・計測・保留を追記する。

## 実装時の裁定

- スティックの受けレイヤーはボタンより下の z-index(5)に置き、ボタンは従来どおり個別に受ける。
  レイヤーはスティック専用で、2 本目の指(別の pointerId)は無視する。
- ノブの見た目の最大移動量は 42px(入力の閾値とは独立)。

## 計測

- テスト 471 件(新規 4 件)全通過、`npx tsc --noEmit` 通過、`npm run build` 成功。
- 描画パスには触っていないため frametime 計測は省略。
- PC 開始地点(`--freeze=true`)は変更前と差分 0。
- タッチエミュレーション(iPhone 13 相当、CDP の実タッチイベント): 触った点に土台円とノブが
  出ることを撮影確認。右へドラッグしたまま 1.6 秒保持でプレイヤーが歩き、画面が大きく
  スクロールした(変化画素 約 109 万)。

## 保留

- 実機でのスティックの感度(閾値 14/18px)と操作感はユーザーの実機確認待ち。
- 感度をユーザー設定にするかは、実機フィードバックを見てから判断する。
