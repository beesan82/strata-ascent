# 改名計画(public 化の前に製品名をオリジナルへ)

> 背景: リポジトリを public にする際の権利リスク監査(2026-11-03)。素材の流用は無い
> (アセット 0 件、全て手続き生成)が、作品名「BLAME!」を製品名に使うこと自体が最大の露出。
> 講談社は公式ページで、刊行物をもとにしたコンピューターソフトの作成・掲載を禁じ、
> 個人への使用許諾も行っていない。対策として公開前に改名する(ユーザーが 2026-11-03 に決定)。
> 新タイトルは本計画の候補からユーザーが選ぶ。選ばれた時点で Task 1〜4 を 1 回で適用する。

## 決定(2026-11-03)

- 新タイトルは **STRATA ASCENT**(リポジトリ名 `strata-ascent`)に決定。重力子砲は **重粒子砲** に改名。
- Task 1・2 と重粒子砲の表示変更はブランチ `chore/rename-strata-ascent` で適用済み
  (検証: テスト 463 件通過 — 全並列では既知の worldgen タイムアウトフレーク 1 件、単独再実行で 36/36 通過。
  tsc・build 通過。スクリーンショットで HUD の「重粒子砲 3/3」表示を確認)。
- 残りは所有者の GitHub 操作: リポジトリ名を `strata-ascent` へ rename → public 化。
  Task 3(内部記録の旧名)は第 2 弾として未着手。

## 候補(衝突チェック済み、2026-11-03 に Web 検索で完全一致の既存ゲーム無しを確認)

| 候補 | 読み / リポジトリ名 | 備考 |
|---|---|---|
| STRATA ASCENT | ストラータ・アセント / `strata-ascent` | 「層を登る」が直訳で伝わる。近接作に Strata(2014、パズル)、Astral Ascent があるが完全一致なし |
| PLATEBOUND | プレートバウンド / `platebound` | 界面の「板」に縛られ・板を目指す二義。一語で独自性が高い。完全一致の使用例なし |
| SILENT STRATA | サイレント・ストラータ / `silent-strata` | 静寂と層。雰囲気寄り。完全一致なし |
| 登層者 | とうそうしゃ / `tososha` | 日本語タイトル。主人公の呼び名にもなる。完全一致なし(別名「塔を登る者」というアプリはある) |
| 界面登攀 | かいめんとうはん / `kaimen-tohan` | 本作の設計用語そのまま。独自性は高いが一般には伝わりにくい |

重力子砲の改名案(表示名のみ。コード識別子 `Graviton` は物理学の一般語なので残す):
**重粒子砲**(推奨)/ 集束ビーム砲 / 荷電粒子砲。
