## 実装時の裁定

- **貴重品の敵ドロップは区間の末尾に足した。** 全地区・全敵種で 4 種の合計が上限 62% に届かない（最大は居住区画の Walker で 53.6%）ので圧縮はかからず、回復・糧食・素材の当たりは段階 3-B 前と同じロールで同じ結果になる。従来 null だったロールの一部（約 2%）が貴重品になる。
- **地区倍率は `DROP_PROFILE` の `valuable` 列で持ち、初期値は全地区 1.0。** 設計の「既存の地区倍率に乗せる」を、素材と同じ列を足す形で満たした。地区ごとの寄せは調整時にこの列だけを変える。
- **キャッシュの貴重品 5% は消耗品 3 種の取り分から引いた。** 素材の 20% は変えず、消耗品 3 種は従来の地区別比率のまま 80% → 75% に縮む。区間の境界が動くので、同じキャッシュ ID でも境界付近のロールは段階 3-B 前と中身が変わる。既存テストの固定値（寒鋼の 0.4／0.2／0.2、居住の 0.44／0.28／0.08）は ×0.75 の値へ更新した。
- **ボス報酬は末尾に追加（総数 4）。** 出現位置は中心と右の間（+0.75）。回復・砲弾は従来どおり通常ドロップ（寿命 60 秒）、糧食と貴重品は補給品（寿命なし）。
- **貴重品の地面上限は設けない。** `GROUND_LIMIT` に入れず、補給品全体の上限だけに従う（入手が低確率で、溢れ処理で貴重品が消えるのを避けるため）。
- **遺留品の構成は「携行（CARRY_KINDS 順）→ 糧食」。** 位置は ±0.75 の幅に等間隔で並べ、幅は段階 3 の糧食 2 個（±0.75）から広げていない。携行 5 ＋糧食で最大 7 個前後が 1.5 タイル幅に重なり気味に並ぶが、安定接地点から離れて壁・段差の向こうへ落ちることを避ける方を取った。糧食 2 個だけのときの位置は段階 3 と同じ（`remainsOffsets(2) = [-0.75, 0.75]`）。
- **ロストは `dropRemainsOnDeath` の中で行う。** 構成を取ってから `loseCarry` で携行を 0 にし、その後に実体を置く。遺留品の箇所の追加・3 箇所目での追い出しは既存の `addRemainsSite` のまま（落とす物が増えただけ）。
- **純粋関数の置き場所。** 構成とオフセット（`remainsDropKinds`・`remainsOffsets`）は `core/remains.ts`、携行を 0 にする遷移（`loseCarry`）と確保額（`securedValue`）は `core/carry.ts`。`core/remains.ts` は `entities/drop.ts` の `dropKindFor` を使う（対応付けを 1 か所に保つため）。
- **確保字幕の引数は「素材の個数」と「貴重品の個数」に分けた。** 第 2 引数は省略可能で、省略時は従来の文言・従来の呼び方のまま（既存テストはそのまま通る）。main は `secured.moved - secured.valuables` を素材の個数として渡す（非弾薬は素材と貴重品だけ）。額は今回確保したぶん（累計ではない）を「確保額 +X」で出す。累計は箱の状態セクションで見る。
- **確保額の表示は数値だけ（単位なし）。** 通貨を作らない設計なので「円」などの単位は付けない。桁区切りもロケール依存を避けて付けていない。0 より大きいときだけ値を金色（`.v.gold`）にする。
- **保管チップの文言は従来どおり「貴重品 ×N」。** 額は状態セクションの「確保額」に集約した。
- **見た目。** ゲーム内のドロップは金 `#caa64a`（パレット実在色、糧食と同色）の菱形を行ごとの 1px 矩形で刻み、中央に淡色 `#c7d0ce` の 1 点。糧食（金の横長＋暗い切り欠き）とは形で分ける。描画パスは増えていない（既存のドロップ分岐に 1 つ足しただけ、`lighter` なし）。アイテムボックスのアイコンは DOM/CSS（量子化対象外）で同じ色の菱形。
- **取得音は専用ファイルを足さない。** 回復の素材 `pickupHeal` をレート 1.3 で鳴らす。素材が読めないときの合成音は G5→D6 の上行 2 音（回復の 2 音と聞き分けられる）。
- **既存テストの書き換え。** 種別を足したことで値が変わる期待値（`CARRY_KINDS` の並び、個数レコードの `toEqual`、`dropProfileFor` の `toEqual`、ボス報酬の総数、キャッシュ表の固定値、敵ドロップの「何も落ちない」割合 64% → 62%）だけを更新し、テストの意図（何を固定しているか）は変えていない。

## 保留

- **未検証。** このセッションではテスト・tsc・build・スクリーンショット・計測を実行していない。親側で確かめる。
- **死亡で弾薬が全て遺留品になる。** 復活直後は砲弾 0・パルス 0（装填 0 ＋セル 0）になり、遺留品を回収するまで撃てない。設計どおりだが、遺留品が回収困難な場所（敵の近く、掘らないと戻れない場所）にあると詰まりやすい。休憩点の備蓄は初回だけなので、弾薬の救済（復活時の最低限の弾、休憩点での補充など）が要るかはプレイで判断する。
- **素材の地面上限 8 が遺留品を削り得る。** `pushSupply` の素材上限（8 個）は遺留品の素材も数えるので、地面に素材が多い状態で死亡・撃破が重なると、古い素材（遺留品の素材を含む）が点滅して消える。糧食（上限 16）も同じ仕組みだが、素材は 2 箇所 × 最大 5 個で上限に届き得る。遺留品を上限の対象外にするかはプレイで判断する。
- **補給品全体の上限 32 は遺留品の配置では見ていない。** 段階 3 の糧食と同じく、遺留品は `canAddSupply` を確かめずに置く（落とせないと携行が消えるため）。全体が一時的に 32 を超え得る。
- **遺留品が多いと 1.5 タイル幅に重なって並ぶ。** 見分けにくければ、2 段に積む・幅を地形を見て広げるなどを検討する。
- **貴重品の確率（敵 2%・キャッシュ 5%）と地区倍率（全地区 1.0）は初期値。** プレイで調整する。
- **確保額は永続化しない**（設計どおり、段階 D で判断）。
