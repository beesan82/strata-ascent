# 設計: 敵グラフィック強化とライトの壁遮蔽（2026-11-10）

本人の要望（2026-11-10）:

1. 敵のグラフィックを強化してほしい。
2. 壁の中まで明るいのがおかしい（ライトが壁を貫通している）。

## 1. ライトの壁遮蔽

現状: Lighting は暗幕をプレイヤー中心の円と照準方向のコーンで destination-out 消去するだけで、壁の向こう側や壁の内部まで明るくなってしまう。

- プレイヤー補助光（円）とライトコーン（扇）の消去形状を、**レイキャストで壁に遮られた多角形**に変える:
  - 純粋関数として、中心・半径・角度範囲・タイル参照からレイを複数方向へ飛ばし、固体タイルに当たった点（壁面）で止めた端点列を返す。壁面そのものは照らされる（端点は壁の表面に置く）。
  - 円は全周、コーンは扇の範囲だけレイを飛ばす。レイの本数と刻みは性能と見た目の兼ね合いで決める（開始値は円 48 本・コーン 40 本、刻み 0.25 タイル程度）。
  - グラデーション自体は従来どおり中心からの放射で、多角形のパスの内側だけを塗る。
- タイル参照が渡らない呼び出しでは従来の形状にフォールバックする。
- 決定論を守る（レイはプレイヤー位置と角度だけから決まる。Math.random() は使わない）。
- 性能: レイキャストは毎フレームの追加コストになる。frametime の lighting / render の p50 で前後を測り、悪化が +0.5ms を超える場合はレイ本数・刻みを調整して収める。

## 2. 敵グラフィック強化

対象は歩行敵・飛行ドローン・固定砲台（ボスは専用ポーズが既にあるので対象外）。平坦な色・既存パレット・描画パスを増やさない、の決まりの中で作り込む:

- **歩行敵**: 脚を関節付きにして歩行位相（移動距離から決まる）で動かす。胴にパネルラインとセンサー、進行方向を向く発光する目。向きは移動方向に追随。
- **飛行ドローン**: 回転するローター（半透明の円盤で表現）、点滅する航行灯（時刻から決定的に）、下面のセンサーアイ（追尾中はプレイヤーの方を向く）、移動時のスラスターの光。
- **固定砲台**: プレイヤーを狙う砲身（発射方向に回転）、発射間隔に合わせた警告灯（撃つ前に強まる）、台座の作り込み。
- アニメーションは実体の状態と時刻から決定的に導く（ポーズの純粋関数に切り出せる部分は単体テストで固定する）。

## バージョン

2.12 とする。

## やらないこと

- ボスの見た目の変更。
- 敵の行動・当たり判定・数値の変更（見た目だけ）。
- 光源の追加（ビーコンや塔の灯など他の光の遮蔽は今回は対象外。プレイヤーの補助光とコーンだけ）。
