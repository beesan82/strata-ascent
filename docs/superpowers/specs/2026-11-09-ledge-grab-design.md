# 設計書: 段階2 — 崖つかみ（レッジグラブ）（2026-11-09）

## 背景

- 本人の希望（2026-11-09）: 「登る時とかに、端っこに捕まるとか。そういうアクションは増やしてほしい」。段階制の段階2として、移動アクションの第一弾に崖つかみを入れる。
- 現行の移動は歩行・ジャンプ（コヨーテ/バッファあり）・梯子のみ。段差の縁に手が届く場面でも、ジャンプが届かなければ落ちるだけだった。

## 仕様

### 掴まりの成立

次のすべてを満たすとき、自動で掴まる（ボタン操作は不要）:

- 空中で、落下中（vy >= 0）
- 壁方向へ移動中、または壁に押し付けている（水平入力が壁側、もしくは水平速度が壁側）
- 体の上部（手の届く範囲＝体上端から 0.7 タイル下まで）の高さに、横方向に固体タイルがあり、そのタイルの**上**が空いている（＝縁である）
- 縁の上に、よじ登った後の体が収まる空きがある（登れない縁には掴まってもよいが、登る操作だけが無効。判定は登る時に行う）
- 直前の解除から 0.25 秒以上経っている（解除直後の再掴まりループ防止）

判定は純粋関数 `findLedge(body, tiles, side)`（`src/entities/physics.ts`）に切り出し、Vitest で固定する。梯子タイルは固体ではないため干渉しない。

### 掴まり中

- 重力を受けず、その場に静止する。位置は「手が縁の上面にかかる」見た目にスナップする（体上端が縁の上面より少し下、体の側面が縁の側面に接する）。
- 満腹度の減りは静止中扱い（既存の静止倍率に相乗り）。
- 武器は使えない（発射・溜め入力は無視）。被弾したら掴まりは解除され、通常のノックバックを受ける。

### 解除と よじ登り

- **上入力 または ジャンプ入力**: よじ登る。縁の上に立った位置へ即座に移動する（移動先が固体と重なる場合は登らず、掴まりを維持）。登った直後は通常の地上状態。
- **下入力**: 手を離して落下する（押し出しなし）。
- **縁から離れる方向の入力**: 手を離し、壁から離れる向きへ小さく押し出して落下する。
- どの解除でも再掴まりクールダウン 0.25 秒が付く。

### 描画と手触り

- 掴まり中のポーズをプレイヤー描画に追加する: 腕を縁へ伸ばし、体が縁からぶら下がる形。既存のポーズ決定の仕組み（歩行 gait 等）に相乗りし、新規パスは足さない。
- 掴まった瞬間にハプティクス Light（既存のハプティクス対応表に 1 行追加）。音は、既存の着地音イベントに相乗りできる場合のみ小音量で流す。できなければ無理に足さない（裁定を計画書に残す）。

## やらないこと

- 壁蹴り・壁ずり（ウォールスライド）等の他のアクション（次の候補として保留に記録するだけ）
- スタミナ等の新規リソース
- 掴まり中の射撃
- ワールド生成・地形の変更

## 受け入れ基準

- `findLedge` の単体テスト（成立・不成立の境界: 縁の上が塞がっている／手の範囲外／固体でない）が通る。
- Player のテストで、落下→掴まり→よじ登り→地上、落下→掴まり→離して落下、被弾で解除、が再現できる。
- スクリーンショットで掴まりポーズが確認できる。
- `npm test` / `tsc` / `build` 全通過。frametime の render p50 悪化 +0.5ms 以内。
- MARKETING_VERSION を 2.2 に上げる。
