# Super Metroid級ビジュアル刷新 設計書

日付: 2026-07-12
ステータス: 承認済み
前提: ビジュアル刷新(弐瓶ディテール, 2026-07-11)完了後の、より高精細なルックへの再刷新

## 背景と決定

プレイテストで「まだ描画が貧相。Super Metroid級がほしい」との評価。方向性を以下に決定:

- **基本方針**: 明るく色付きに転換。Blame!の「ほぼ真っ暗+懐中電灯」を捨て、SMのように全体が見える明るい探索空間にする(前回までの闇路線の意図的な上書き)
- **明度**: バイオームごとに変える(暗めの廃墟、明るい大空洞など明度も個性)
- **アート**: タイルセットは「コード生成を主・実CC0素材(Kenney等)を差し替え可能」にするアセット非依存パイプライン(案A)。私はSNES級手描きアートを描けないため、生成タイルを確実な土台とし実PNGを載せる口を用意
- **バイオーム**: 階層ごとに別バイオーム(SMの地域のように独自のタイル・色・明度・背景)

トレードオフ: Blame!の「闇の圧倒感・孤独」はほぼ失われ、SMの「豊かで読みやすい探索空間」になる。これは承認済みの意図的変更。

## ルックと光

- **バイオーム環境光**: 各階層に基準の明るさ(明度)と色。画面全体がその色でうっすら照らされ構造がはっきり見える
- **懐中電灯は補助光に格下げ**: 完全な闇を切り抜く主役ではなく、プレイヤー周囲を一段明るくする光。マウス方向の光は残すが、無くても周囲は見える
- **色付き**: バイオームパレット(3〜5色)でタイル・背景・アクセントを塗る
- **多層パララックス**: 色付きの遠景構造が2〜3層見える

## アーキテクチャ

既存のチャンク焼き込み方式を活かし、「平板塗り+ベクター装飾」→「オートタイル貼り+アクセント」に置換。

```
src/render/
  tileset/
    generate.ts   — コード生成タイルセット(47ブロブ: 面・辺・角・内隅を1枚のアトラスCanvasに焼く)。純粋な描画関数
    atlas.ts      — アトラス(Canvas)+タイル矩形の索引。実PNG差し替え口(loadImageAtlas)
    autotile.ts   — 近傍8タイルのビットマスク → 47ブロブタイルID(純粋関数、ユニットテスト対象)
  biome.ts        — 階層→バイオーム定義(パレット, 環境光の色と明度, タイル色変換, 背景層, アクセント)。純粋
  chunkbake.ts    — 改修: SOLIDをオートタイルでアトラスから貼り、LADDER/装飾アクセントを重ねる
  background.ts   — 改修: バイオームごとの多層色付きパララックス
  lighting.ts     — 改修: 「闇を切り抜く」から「バイオーム環境光+プレイヤー補助光」へ
  playerSprite.ts — 改修: 色付きシルエット(既存の向き・歩行位相を維持)
  post.ts         — 維持(グレイン軽め、ビネットはバイオーム明度に連動)
  renderer.ts     — 合成統括(背景→タイル→装飾→プレイヤー→ライト→ポスト)
```

**データフロー(チャンク焼き込み時)**: worldgenタイル → autotileで各SOLIDの47ブロブID決定 → biome色変換を適用したアトラスから該当タイルをdrawImage → 梯子・配管などアクセントを重ねる。毎フレームはdrawImageのみで性能は現状同等。

**要点**:
- `autotile.ts` と `biome.ts` は純粋関数でユニットテスト可能。見た目はスクリーンショット目視
- タイルセットは起動時に1度だけアトラスへ焼く。実Kenney PNGを同じ索引形式で差し込めば即差し替わる

## バイオーム

| バイオーム | 明度 | 色調 | 背景 |
|---|---|---|---|
| 最下層(配管) | 暗め | 冷たい鋼色+緑青のサビ | 密集した配管シルエット |
| 居住区跡 | 中 | 青緑+生成りのパネル | 崩れた部屋の枠、遠くの窓灯 |
| 廃棄物層 | 暗め | くすんだ琥珀+赤サビ | 瓦礫の山、垂れ下がる構造 |
| 大空洞帯 | 明るい | 冷たい藍+白い霞 | 数百m級の吹き抜け、遠い橋と塔 |
| 上層 | 中〜明 | 蒼白+ネオン差し色 | 異質な幾何構造 |

- 各バイオーム = `{ ambientColor, ambientLevel, tilePalette(3-5色), accentColor, bgLayers[] }` の純粋データ
- **遷移**: 高度でバイオーム係数を線形補間し、環境光の色・明度を数十タイルかけて滑らかに変える

## パララックス背景
バイオームごとに2〜3層(遠景=色グラデ+大構造シルエット、中景=近い構造)。層ごとの視差係数でカメラに追従。決定論的(hash2)。

## プレイヤー
現コート人影を色付きに(バイオーム環境光を浴びた明るいシルエット+リムライト)。向き反転・歩行ボブ・腕は維持。歩行の上下動をrich化。

## ポスト
グレインは大幅に薄く。ビネットはバイオーム明度に連動(明るい大空洞ではほぼ無し)。走査線は入れない。

## テスト方針
- ユニット(Vitest): `autotile.ts`(近傍→47ブロブIDの決定論写像, 代表20パターン)、`biome.ts`(階層→選択, 境界補間0〜1単調+クランプ, パレット値域)。既存全テストは回帰なし維持。gameplay(worldgen/physics)には触れない
- 見た目: スクリーンショットで各バイオーム(高度別)を撮り目視。「SM級か/貧相でないか」を品質ゲートに

## エラー処理
- 実PNGアトラス読み込み失敗 → 生成タイルセットにフォールバック(警告)。生成タイルが常に土台なので必ず動く
- 未知の高度/バイオーム → 末尾バイオームでクランプ

## 段階分け(各段階でスクリーンショット可能)
1. **オートタイル土台** — autotile.ts + 生成タイルセット(1バイオーム)+ chunkbake改修。SOLIDが辺・角付きタイルで貼られる
2. **明るい世界** — lighting.tsをバイオーム環境光へ転換
3. **バイオーム** — biome.ts + 5バイオームの色/明度/遷移、多層パララックス背景
4. **仕上げ** — プレイヤー色付き、ポスト調整、実Kenney PNG差し替え試行、総合チューニング

## スコープ外
- ゲームプレイ変更(worldgen/physics/操作)。今回は描画層のみ
- 段階3-4のゲーム内容(セーフガード・重力子砲・物語)
- 敵/アイテムのスプライト(地形と背景の刷新に集中)
- 音

## ライセンス
実素材を導入する場合はCC0(パブリックドメイン)のみ使用。出典を docs に記録する。参考: Kenney Pixel Platformer(CC0)。
