# 設計: 段差と光（ステップアシスト／階段／深さの明るさ／懐中電灯モード）（2026-11-09）

本人の要望（2026-11-09 夜）:

1. 小さい段差をいちいちジャンプで越えるのが不格好。階段みたいな地形がほしい。
2. 小さい段差くらいはジャンプせずに登れるようにしてほしい。
3. 懐中電灯（ライトコーン）が意味をなしていない。深さ（層）によって明るさを変えてほしい。
4. 向きを変える＝発射になってしまう。発射なしで懐中電灯だけを向けるモードがほしい。

## 1. ステップアシスト（プレイヤーの移動）

- `moveBody` に任意パラメータで段差アシストを入れる（既定オフ、Player だけオン）。
  - **ステップアップ**: 接地した状態で横移動が固体に阻まれたとき、阻んでいる段差が高さ 1.0 タイル以下で、頭上（持ち上げ後の位置）に空間があれば、そのまま上に乗って横移動を続ける。
  - **ステップダウン**: 接地したまま横移動した先で、真下 1.0 タイル以内に床があれば吸着して接地を維持する（1 段降りるたびに落下→着地にならない。着地音・着地ポーズが誤発しない）。
  - 空中では発動しない（崖つかみ・ジャンプ中の壁挙動は従来どおり）。歩行敵・飛行敵・砲台弾には適用しない（巡回挙動を変えない）。
- テスト（physics.test.ts / player.test.ts）: 1 タイル段差を歩いて越える／2 タイルは越えられない／頭上が塞がっていると越えられない／空中では登らない／1 段降りで onGround が切れない。

## 2. 階段生成（ワールド生成）

- 床の高さが隣の列でちょうど 2 タイル上がる場所に、中間段（1 タイル）を置いて 2 段の階段にする。条件: 段の上の 2 タイルが空気であること、保護構造（休憩点の箱・大広間・施設・梯子列・見晴らし台など）の内部や近傍では置かない。
- 決定論を守る: 判定はグローバル座標から計算できる情報だけで行い、チャンク境界で不整合が出ない形にする。挿入に安全な合成点が無い場合は無理に入れず、実装報告で理由を明示して §1 だけを出す（フォールバック）。
- 検証: 既存の到達可能性テスト群が落ちないこと。可能なら既知シードの 2 段差地点に段が入ることをテストで固定する。

## 3. 深さで変わる明るさ

- 環境光に深さ係数を掛ける: 層番号が大きい（深い）ほど暗くする。純粋関数 `depthShade(layer)` を新設し単体テストで固定する。目安: 層 0 で 1.0、1 層ごとに約 0.06 ずつ低下、下限 0.45。
- 適用点は renderer の ambient 計算（biome の ambientLevel と ambientDelta の合流点）。地区ごとの明るさの個性は残し、深さはその上に乗る係数にする。
- 効果: 深部では周囲が暗くなり、相対的にライトコーンが効くようになる。

## 4. 懐中電灯モード（発射なしの照準）

- 眺望ボタン（◎、PC は Shift）を押している間を「懐中電灯モード」とする:
  - 右スティック（PC はマウス）でライトとカメラを向けられる（既存の照準・カメラ先行・眺望の合成をそのまま使う）。
  - **発射しない**: パルスの連射を止め、重粒子砲の溜めも開始しない。入った瞬間に溜め中ならキャンセルする（離した扱いで発射してしまわないこと）。
  - **コーンを強める**: この間だけコーンの半径を約 1.3 倍にし、中心の明るさも上げる（Lighting.render へ係数を渡す）。
- 既存の眺望（ズームアウトとパン）はそのまま併存させる。新しいボタンは足さない。

## バージョン

2.10 とする。

## やらないこと

- 敵の移動へのステップアシスト適用（§1 の裁定どおり）。
- ライトの電池・燃料などのリソース化（今回は意味づけを明るさ側でやる）。
- 新しいボタン・モード表示 UI の追加（字幕も出さない）。
