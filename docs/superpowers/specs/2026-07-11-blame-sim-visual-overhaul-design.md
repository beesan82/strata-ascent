# ビジュアル刷新「弐瓶勉ディテール」設計書

日付: 2026-07-11
ステータス: 承認済み
前提: 段階1-2(2026-07-11-blame-sim-design.md)完成後のルック刷新

## 背景と決定

初回プレイテストで「Blame!感がない、チープ」との評価。ビジュアルコンパニオンで3方向を比較し、以下を決定:

- **方向**: C案「闇+ライトを維持し、照らされた範囲に原作級のディテールを描き込む」(A案「白い虚空」は不採用)
- **密度**: モックアップ(look-c-quality.html)基準でさらに増量。「原作の書き込みを再現」がゴール
- **実装方式**: チャンク焼き込み(密度上限をなくすため)

## 見た目の仕様

すべてシード+ワールド座標から**決定論的**に生成。同じ世界では常に同じ絵。

### 構造体の質感(ライトに照らされて浮かぶ)
- 空気に面したエッジに明るいハイライト線(構造の輪郭)
- 大きな塊はパネル分割: 継ぎ目線+継ぎ目沿いのリベット点
- 塊内部は45°ハッチング。階層(stratum)ごとに密度・角度が微変化
- 壁面装飾(確率配置): 排気グリル、縦配管、点検口
- 床上面: 数〜数十タイル連続する配管(ブラケット留め)、瓦礫の山、段差
- 天井: アンカー間のカテナリーケーブル、切れて垂れる短いワイヤー

### 空間の奥行き
- 闇の奥に2層のパララックス遠景(巨大な塔・デッキのシルエット、不透明度5〜12%)
- フィルムグレイン(全画面、微弱)+薄いビネット

### キャラクター・小物
- プレイヤー: コートの人影(霧亥風)。移動方向で反転、歩行2フレームボブ、ライト方向に腕
- 梯子: 2本レール+踏み桟+一定間隔の背かご
- ライト: 現行の円錐+環境光を維持し、輪郭にノイズディザ+微かな揺らぎを追加

## 技術構成

### チャンク焼き込みパイプライン
- `src/render/decor.ts` — チャンク+周囲1タイルの地形から装飾リスト(線・点・パス・矩形)を計算する**純粋関数**。ユニットテスト対象
- `src/render/chunkbake.ts` — チャンクごとに16px/タイル(1024×1024)のオフスクリーンCanvasへベースシルエット+装飾を焼き込みキャッシュ。ChunkStoreの破棄と連動して解放。描画時はdrawImageで拡縮
- `src/render/background.ts` — パララックス遠景(決定論的、カメラ座標に視差係数)
- `src/render/playerSprite.ts` — コート人影の描画(反転・ボブ・腕の向き)
- `src/render/renderer.ts` — 合成順の統括に縮小: 遠景 → 焼き込みチャンク → プレイヤー → ライト(ディザ+揺らぎ) → グレイン+ビネット
- `src/render/silhouette.ts` — 焼き込みに吸収して削除

### 開発用スクリーンショットハーネス
- Playwright(devDependency)+ `scripts/screenshot.mjs`: devサーバーのページを開き、ゲーム描画後のcanvasをPNGに保存
- 用途: 実装者・レビューエージェントが実画面を目視確認する品質ゲート。以後の見た目タスクの標準検証手段

## テスト方針
- decor: 決定論性(同シード同出力)、整合性(配管は床上のみ、ケーブルは天井のみ、装飾が地形と矛盾しない)
- 焼き込み・描画・グレイン: スクリーンショットの目視確認(自動アサートしない)
- 既存の全テストは回帰なしで維持

## 性能予算
- 焼き込み: チャンク読み込み時のみ、1チャンク数ms以内(既存生成~1msに追加)
- 毎フレーム: drawImage数枚+ライト+グレインで現状同等(60fps維持)
- メモリ: 焼き込みキャッシュは読み込み済みチャンク分のみ(9チャンク×4MB≒36MB上限)

## スコープ外
- A案(白い虚空)への切り替え、空洞の見せ方の大変更
- 敵・武器・物語(段階3-4)
- タイル種の追加(装飾は描画層のみで完結し、ゲームプレイに影響しない)
