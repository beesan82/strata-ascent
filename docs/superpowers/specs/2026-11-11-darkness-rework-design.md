# 暗さの作り直し（暗がりを探索する明るさへ）設計

## 本人の判定（2026-11-11、TestFlight 2.16 実機）

「全然壁の中暗くないぞ。横からのっぺり全体が明るい。暗がりを探索してる感じは全然ないな」

2.16 の遮蔽（光が壁を越えない）は正しいが、暗さの量が根本的に足りない。数値で見ると当然で、現行の式は:

- 地区の ambientLevel: 0.28（最下層）〜0.7（大空洞帯）
- 暗幕（Lighting）: `dark = min(0.62, (1 - ambient) * 0.72)` → 典型的な地区で 0.22〜0.32、最も暗い地区でも 0.52 しか暗くならない
- 深さ係数の下限 0.45、囲まれ係数の下限 0.55（どちらも ambient への乗算で、暗幕の上限 0.62 が頭打ち）

つまり世界はいつも 5〜8 割の明るさで描かれ、光の内と外のコントラストが付かない。これが「のっぺり全体が明るい」の正体。

## 方針: 暗いのが既定、光は例外

1. **地区 ambientLevel を全体に下げる**（目安 ×0.5〜0.6）。空・遠景の色も ambientLevel から作られるので、背景ののっぺりした明るさも一緒に落ちる。地区ごとの相対的な個性（大空洞は他より明るい等）は保つ。
2. **暗幕の上限を上げる**: 0.62 → 0.86。係数も (1 - ambient) * 0.72 → より急に（目安 ×1.0）。光源のない場所は「シルエットがかろうじて読める」濃さまで落とす。
3. **深さ・囲まれの下限を引き下げる**: depthShade 下限 0.45 → 0.30、1 層ごとの減衰 0.06 → 0.08。enclosureShade 下限 0.55 → 0.35、効き始めも開放度 0.55 より手前（0.7）から。深く・囲まれるほど暗い、が体感できる勾配にする。
4. **光の側は維持〜微増**: プレイヤー補助光とコーンの「暗幕を消す強さ」は現行維持を起点に、暗幕が濃くなる分だけ相対的に際立つ。懐中電灯モードの価値が上がるのは歓迎。半径は変えない。
5. **発光物は暗闇でこそ見える**: 敵の目・航行灯・警告灯のような発光部が暗幕の下で消えるようなら、発光部だけは暗幕の後に描く（既存の描画順の範囲で。新しいパスは足さない）。要否は実装時に描画順を確認して判断し、計画書に記録する。

## 守るもの

- 真っ黒にはしない: 暗幕の上限 0.86 + 地形のシルエットが読めることをスクリーンショットで確認する。スポーン直後・休憩点まわりは特に確認する。
- 光源の色・数、敵やドロップの数値、懐中電灯の角度・半径は変えない。
- frametime への影響なし（式と定数の変更のみ）。

## 検証

- 前後スクリーンショット: スポーン付近（層 0）、囲まれた室内（2.16 の構図 4 = 253,224）、大穴の前室（構図 A = 250,69）、深い層の 4 構図で平均輝度と見た目を比較する。
- 単体テスト: depthLight / lighting の係数は既存テストの期待値を新しい設計値へ更新し、固定する。
- 最終判定は実機（本人の「暗がりを探索してる感じ」が正）。
