# 設計書: 資源と武器の再設計（両武器消費型・武器庫・UI集約）（2026-11-09）

## 本人の方向（2026-11-09 夜）

- タッチボタンの文字ラベル（跳・パルス・箱・望）がダサい → アイコンにする。
- 状態と弾の表示は全部アイテムボックス画面へ持っていく。
- 銃は消費型にして、アイテム管理の上にちゃんと乗せ、緊迫感が発生するようにする。
- パルスも制限ありにする。
- 弾薬は「武器庫」のような、フィールドに意味のあるエリアを作って回収できるようにする。
- 敵を倒すことが全てじゃないようにする。

## 仕様

### 1. 両武器とも弾薬アイテム制

- 重粒子砲: 自動回復を廃止。砲弾（携行種別 `shell`）を撃つたびに 1 個消費する。溜め（0.6 秒）の儀式は従来どおり。
- パルス: パルス弾セル（携行種別 `pulsecell`、1 セル = 20 発）を消費する。装填中の残発数が尽きたら次のセルを自動で装填する（装填も携行枠を 1 個使う）。
- 弾薬は素材と**携行枠（5）を共有**する。保管（確保済み）にも置け、休憩点で引き出せる。ボックスの出し入れ（落とす・引き出す）は弾薬にもそのまま効く。
- 初期所持はパルス弾セル 2 個（40 発）のみ。砲弾はゼロから現地調達する。
- 弾切れのとき武器は撃てない。敵は素通りでき、死亡しても携行は残る（段階 A の決定）ため、詰みにはならない。

### 2. 武器庫エリア（弾薬の回収場所）

- フィールドに「武器庫」を決定論で配置する。既存の補給キャッシュの仕組み（近傍に最大 1 つ、接触で開封）に相乗りする別種のスポットとして実装する。
- 武器庫は通常キャッシュと見た目を変える（弾薬のクレート）。開封すると弾薬が複数出る（砲弾 1 ＋ パルス弾セル 2 を基本形とする）。
- 密度は地区で変える（電力区・精錬区は濃く、水域・生体は薄く）。開封済みはセッション内で再訪しても復活しない（休憩点備蓄と同じ）。

### 3. 資源の主経路は「場所」、敵は従

- 敵ドロップから弾薬（砲弾セル）を外す。敵は素材（従来どおり）と回復・糧食は落とすが、弾薬は落とさない。
- 休憩点の初回補給を「糧食 1 ＋ 弾薬 1」に寄せる（弾薬はパルス弾セルか砲弾をハッシュで決める）。
- 通常の補給キャッシュは従来の構成を維持する。
- ボス報酬の砲弾 1 は残す（場所性のある報酬として）。

### 4. UI の集約

- アイテムボックスに**状態セクション**を追加する: HP、満腹度と糧食、パルスの残弾（装填中＋セルの換算総数）、砲弾の携行数、現在の階層と高度、最深記録、確保済みの総数。
- フィールドの HUD 文字行は撤去し、ボスの HP バーだけを残す。字幕（満腹度低下の警告など）は従来どおり。
- タッチボタンはアイコン化する: 跳 = 上向きの矢印、望 = 照準環、箱 = 格子、武器 = 現在の武器を示す記号（パルスは連射の記号、砲は大きな弾の記号。砲モードの紫の明示色は維持する）。

## やらないこと

- 弾薬の永続化（段階 D の判断に従いセッション内）。
- 近接攻撃などの新武器。弾切れ時の保険は「逃げる」こと自体とする。
- パルスの連射速度・威力の変更。

## 受け入れ基準

- 弾薬の消費・装填・取得の遷移が単体テストで固定される（Graviton の自動回復に依存した既存テストは置き換える）。
- 武器庫の配置が決定論で、同じシードで同じ場所に出ることがテストで固定される。
- `npm test` / `tsc` / `build` 全通過。frametime の render p50 悪化 +0.5ms 以内。
- スクリーンショット: 箱画面（状態セクション）、アイコン化したボタン（タッチ表示）、武器庫の見た目。
- MARKETING_VERSION を 2.6 に上げる。
