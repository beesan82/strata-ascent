# 設計書: アイテムボックス（いつでも開ける保管・携行UI）（2026-11-09）

## 背景

- 段階 A（2.4）で携行と確保の仕組みは入ったが、表示は HUD の数字のみ。本人の指摘「タルコフとかアークレイダースみたいなアイテムボックスみたいな要素はどこ行ったん？」＋追加の希望「いつでも開いて出し入れしたりできるように」。
- 本作の UI は DOM が担っている（字幕、タッチボタン、HUD）。ボックスも DOM のパネルとして作り、既存の流儀に合わせる。

## 仕様

### 開閉

- いつでも開ける: タッチ側は専用ボタン（箱アイコン）を追加、PC は KeyB。Esc でも閉じる。
- 開いている間、ゲームの進行は止まる（プレイヤー・敵・満腹度は進まない）。描画は現在のフレームを維持する。タルコフと違いポーズを許すのは、スマホでの操作性を優先する割り切り。
- 武器の溜め中など、開いたら危険な状態では開いた瞬間に溜めを破棄する（既存のキャンセル規則に合わせる）。

### パネルの中身

- **携行エリア**: 枠ぶんのセル（現行 5）を並べ、入っているアイテムを 1 個＝1 セルで表示する。アイコンはアイテムの色と形（素材＝鋼青）を小さく描く。
- **保管エリア**: 確保済みのアイテムを種別ごとの個数で表示する（保管は無制限）。
- 空のセルは枠だけ見せ、「何個まで持てるか」が一目で分かる形にする。

### 出し入れ

- 携行のアイテムをタップ → その場に 1 個落とす（補給品として地面に置かれ、また拾える）。枠を空けたいとき、要らない物を手放すための操作。
- 保管のアイテムは、**休憩点にいる間だけ**タップで携行へ 1 個戻せる（枠に空きがある場合のみ）。戻した物は未確保に戻る。休憩点の外では保管エリアは閲覧のみで、その旨をパネル内に小さく表示する。
- 保管への預け入れは従来どおり休憩点到達で自動（確保）。手動の預け入れ操作は作らない（開くたびに安全になる抜け道を作らないため）。

## やらないこと

- グリッドへの自由配置、ドラッグ＆ドロップ、アイテムの回転（タルコフのテトリス部分）。セルは自動で詰める。
- 消耗品（砲弾・回復・糧食）のボックス表示。これらは従来どおり即時消費／所持カウンタのまま。
- 保管の永続化（段階 D の判断に従う。現行はセッション内）。

## 受け入れ基準

- 開閉・ポーズ・出し入れの状態遷移が単体テストで固定される（携行の取り出し、保管からの引き出しの可否）。
- スクリーンショットでパネル（携行セルと保管）が確認できる。
- `npm test` / `tsc` / `build` 全通過。frametime の render p50 悪化 +0.5ms 以内（パネルは DOM なので描画負荷は増えない想定）。
- MARKETING_VERSION を 2.5 に上げる。
