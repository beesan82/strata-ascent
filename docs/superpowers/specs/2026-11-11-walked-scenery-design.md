# 歩く景色の作り込み（ニヒリズムの景色）設計

## 本人の問題提起（2026-11-11）

「前よりは遊べるものになってるけど、まだ全然おもんない。雰囲気がない。アクション面は一旦置いといて、このゲームの最大の見どころは完備的な世界の旅。背景はおもろいけど、歩くところが全然おもんない。面白みのない景色。ニヒリズムを感じない」

遠景（backdrop）は評価されている。問題は足元＝歩行空間の見た目が均一な躯体の床と壁で、装飾も配管・ケーブルトレイ等の接合ディテールに寄っていること。目指すのは「人のためじゃない規模の世界が、人はもういないのに続いている」手触りを、歩く場所そのものに出すこと。

## 範囲の裁定

- **当たり判定のある地形（worldgen）は変えない**。到達可能性・スポーン・経路へのリスクを避ける。変えるのはチャンク焼き込みの装飾（`src/render/decor.ts` の `decorateChunk`、純粋関数・決定論・チャンク境界一致が既存テストで固定されている経路）と、その見せ方だけ。
- 描画パスは増やさない。すべて既存の焼き込みへの相乗り。
- 色数は既存パレット（STEEL 系＋錆）の範囲。新色を足す場合は錆・暗色系に限る。

## セット内容

### A. 残滓（床と壁際の「残されたもの」）

歩行空間の床面・壁際に、世界の残滓を置く。すべて装飾（すり抜ける）で、床の上面に接地して描く。

- **機械の残骸**: 歩行敵より一回り大きい機械の倒れた・座り込んだシルエット。輪郭＋関節の折れ＋錆筋。頻度は低く（見つけると印象に残る程度）。
- **積まれた板・塊**: 床に積まれたスラブ状の塊の山。誰かが運んで、途中で置いていった形。
- **倒れた梁**: 壁際から床へ斜めに倒れかかった梁（描画のみ、通れる）。
- **破片の野原**: 既存の debris を点ではなく「範囲」で敷く場所を作る。崩れた場所の足元。
- 配置はハッシュで決定論。休憩点・スポーンの保護範囲と、梯子・出入口の真上/真下は避ける（視認性の保護は既存装飾と同じ流儀）。

### B. 構造の造形（壁面と天井の「規模」）

- **頭上の桁渡り**: 通路の天井付近を横切る太い桁・ガーダーの影と受け光。歩くたびに頭上を巨大な構造が横切る感覚を作る。プレイヤーの頭より十分上にだけ出す（当たり判定と誤認させない）。
- **深い壁ベイの内側**: 既存の凹ベイを深くし、内側に小さな残滓や配管の束のシルエットを入れる。「壁の中にも空間と物がある」読みにする。
- **巨大壁面のステンシル**: 長く続く壁面に、タイル数個分の大きさの薄い番号・区画記号をまれに描く。壁が「巨大な何かの表面」に読めるようにする。文字化け・固有名詞は使わない（数字と単純な記号のみ）。

### C. 地区ごとの足元の個性

- 装飾モチーフの出方に地区バイアスを付ける（既存の `terrainProfileFor` と同じ流儀の表を decor 側に持つ）。例: 居住区画は残滓とステンシルが濃い、廃棄沈殿層は破片の野原と倒れた梁、電力区は桁渡りと太い配管束、精錬区は錆とスラブの山、大空洞水域はベイと桁で「空間の巨大さ」寄り、寒鋼基層は均一で寒い（薄め）、生体異物区は既存の生体装飾に残滓を混ぜる。
- バイアスは「濃さと種類の重み」だけを変え、地区をまたいでもチャンク境界で破綻しないこと（装飾はチャンク単位で決定論、という既存の不変条件を守る）。

## 検証

- 決定論・チャンク境界一致の既存テスト群がそのまま合格線。新モチーフにも境界一致のテストを足す。
- 前後スクリーンショット: 同じシード・同じ位置で、残滓の出る床・桁渡りの通路・ステンシル壁面の 3 構図。見た目の最終判定は実機（本人の「雰囲気」判定が正）。
- frametime は焼き込み時だけのコストで、フレーム単価への影響はチャンク生成時のみ。render p50 の悪化 +0.5ms 以内（従来の合格線）。

## 保留として明示

- 当たり判定のある造形（通路を割る巨柱など）は次段階の候補。今回は視覚だけ。
- 点滅する標識灯のような動的な残滓は、動的描画の相乗り先（infraSprite の fx 相）を別途検討する。今回は静的な残滓に限る。
