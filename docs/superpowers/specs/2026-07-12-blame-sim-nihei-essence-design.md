# 弐瓶勉らしさ再生 設計書

日付: 2026-07-12
ステータス: 承認済み(ユーザーレビュー待ち)
前提: SM級ビジュアル刷新・階層ワールド生成・重力子砲(段階3)完了後の、作風(弐瓶勉らしさ)の再獲得

## 背景と決定

プレイテストで「まだ弐瓶勉らしさが出ていない」との評価。原因を作風分析で特定した:
`supermetroid-look` 転換で**闇と圧倒スケールを意図的に捨てた**ことと、そもそも**建築的奥行きが無い平面**であることが主因。

弐瓶作品の美学を重要度順に分解すると:
1. **人間を虫けらにするスケール** — 構造が画面の主役、人間は豆粒。"床"ではなく"渓谷の壁"
2. **建築的奥行き(Z軸)** — 梁・配管が消失点へ吸い込まれる。構造が画面奥へ厚みを持つ
3. **闇と虚無** — 光は稀・硬質・局所。構造は距離で純黒に溶ける
4. **非反復の累積構造** — 整ったタイルではなく、増築・崩壊し続けた無秩序
5. **極微ディテール×巨大な平面の対比**
6. **バイオメカニカルな不気味さ**
7. **孤独・疎外・崇高**

現状(SM-look後)は「整った探索プラットフォーマー」で、①②③④が弱い。

### 方針決定(ユーザー承認済み)

- **明暗はバイオーム別に振る**: 大空洞帯・上層は闇と圧倒スケール全開、居住区など機能施設は明るめ。**明→暗の落差そのものを弐瓶的演出**に使う(SM-lookの投資を活かしつつ闇を取り戻す)。
- **取り組むレバーは4つ**: 建築的奥行き(Z軸) / 圧倒スケール(豆粒化) / 非反復の累積構造 / キリィ風の主人公。
- **奥行きは擬似3D押し出し**: プレイフィールドは平面のまま、露出面を消失点方向へ後退させ厚みを与える(断面透視やパララックスのみは不採用)。

### トレードオフ

- 描画層とカメラ・worldgen尺度に集中し、**物理(`physics.ts`)は無改修**。worldgen の尺度変更のみゲーム地形に影響(到達可能性テストを更新)。
- 焼き込み方式ゆえ「カメラ追従の本物の消失点」は初期スコープ外。固定方向の後退内面＋パララックスで擬似的に作り、必要なら段階3のスクショ判断で動的押し出しを後付けする。

## レバー別設計

### 0. 土台 — バイオーム別の明暗

`biome.ts` の `ambientLevel` を振り直す。

| バイオーム | ambient方針 |
|---|---|
| 大空洞帯 | ほぼ闇。光は局所のみ。圧倒スケールの見せ場 |
| 上層 | 闇寄り。異質さと静寂 |
| 廃棄物層 | 暗め |
| 最下層(配管) | 暗め |
| 居住区跡・機能施設 | 中〜明(SM-lookの読みやすさを維持) |

- `lighting.ts`: 闇バイオームでは補助光を「虚無を切り抜く硬い局所光(狭い環境半径＋マウス方向の円錐)」に、明バイオームでは現状の環境光を維持。`ambientLevel` を光の性格の切り替え係数として使う。
- `post.ts`: 既存の `ambientLevel` 連動ビネットを活かし、闇で強く・明で弱く。
- **落差の演出**: 既存のバイオーム線形補間を活かし、明るい機能施設から闇のバイオームへ抜ける遷移を数十タイルかけて体感させる。追加ロジックは不要(補間の値域調整のみ)。

### 1. 建築的奥行き — 擬似3D押し出し(描画層のみ)

3点セットで「構造の中にいる」感を作る。

- **後退内面(厚み)** — `chunkbake.ts`
  空気に面したSOLIDのエッジから、奥へ後退する暗い内面帯を焼き込む。上面は床の厚み、側面は壁の奥行きを表す。奥ほど純黒へグラデーション。焼き込み画像はチャンク固定なので、**押し出し方向はタイルローカルで固定**(例: 露出面から一定オフセットで内側へ、上面は下方向＋僅かに横、側面は横方向)。カメラ追従の消失点は持たないが、構造に一貫した厚みが出る。
  - 押し出しジオメトリ(エッジ→台形頂点)は**純粋関数**として切り出しユニットテスト対象にする。
- **近景オクルーダ層** — `render/foreground.ts`(新規)
  プレイヤーより手前を、ぼやけた暗い構造シルエットが時折横切る(背景パララックスの対称)。決定論的配置(hash2)、カメラ追従率は 1.0 超(手前ほど速く流れる)。合成順は最前面(post直前)。
- **背景の消失点収束線** — `background.ts`
  遠景に消失点へ集まる構造線(梁・配管の透視線)を淡く足し、透視の錯覚を強める。既存パララックス層への加算。

**合成順(改訂)**: 背景フィル → 遠景パララックス(＋消失点線) → 焼き込みチャンク(＋後退内面) → プレイヤー → ライト → 近景オクルーダ → 重力子砲FX → post。

**動的押し出し(オプション)**: 段階3のスクショで固定押し出しが物足りなければ、可視タイルの露出エッジをカメラ中心消失点で毎フレーム押し出す方式を後付け検討する(初期スコープ外)。

### 2. 圧倒スケール — 豆粒化

- **カメラのズームアウト(主役・独立実装可)** — `camera.ts` / `renderer.ts`
  `camera.ts` に `zoom`(目標倍率への平滑追従)を追加。renderer は固定の `VIEW_TILES_X = 44` を `VIEW_TILES_X / zoom` 相当で動的化し `ppt` に反映。開放度(プレイヤー周囲のSOLID密度が低い=大空洞)を測り、開放空間で横90+タイル相当までズームアウト、狭い通路では44へ戻す。人影が豆粒になる。
  - 開放度→目標ズームの写像は**純粋関数**でユニットテスト。
- **worldgen の尺度** — `worldgen.ts` / `strata.ts` / `network.ts`
  大空洞帯を数百タイル級の本物の吹き抜けに拡大。幹線に巨大な垂直昇降路。到達可能性は維持(`worldgen.test.ts` の到達性テストを尺度変更に合わせ更新)。

### 3. 非反復の累積構造

- **タイル外観バリアント** — `render/tileset/generate.ts` / `chunkbake.ts`
  均一な47ブロブに、ワールド座標ハッシュで損傷・腐食むら・剥がれ・割れ線を決定論的に重ねる。同型タイルでも二つと同じ見た目にしない。
- **不規則な塊** — `decor.ts`
  SOLID輪郭にグリッド非整列の突起・欠け・飛び出した鉄筋を装飾で追加。**当たり判定は矩形のまま、見た目だけ崩す**。
- **増築の重なり** — `decor.ts`
  既存のパネル継ぎ目を複数「世代」(角度・密度違い)で多重化し、単一グリッド感を壊す。領域(region)ハッシュで世代パラメータを決定論化。

### 4. キリィ風の主人公 — `playerSprite.ts`

- コートを長く重く、裾のはためき(`walkPhase`連動)。
- 重力子砲を構える腕の明確化(現在のライト方向の腕を強化)。
- 無表情で静的な佇まいの重心。
- 闇バイオームでは輪郭が闇に沈み、光側の輪郭(リムライト)だけが浮かぶ。既存の向き反転・歩行ボブは維持。

## 段階分け(各段階が動く縦スライス・スクショ確認)

1. **豆粒化** — カメラズームアウト＋worldgen尺度拡大。効果が最も明快で独立
2. **明暗の落差** — バイオーム別 ambient 再調整＋闇バイオームのライティング
3. **奥行き** — 後退内面＋近景オクルーダ＋背景消失点線
4. **累積構造** — タイルバリアント・不規則塊・多重継ぎ目
5. **キリィ＋総合チューニング**

各段階は独立した実装計画(spec→plan→実装)とし、段階ごとにレビューとスクリーンショット確認を行う。

## テスト方針

- **ユニット(Vitest)**: ズーム写像(開放度→倍率, 単調＋クランプ)、`biome` ambient補間(値域・境界)、タイルバリアントの決定論(同座標同出力)、押し出しジオメトリ(エッジ→台形頂点)の純粋部分。既存全テストは回帰なし維持。`physics.ts` には触れない。
- **worldgen 尺度変更**: 到達可能性テスト(上方向ルートの存在)を新尺度に合わせ更新。決定論は維持。
- **見た目**: 各バイオーム(高度別)＋開放/閉鎖空間でスクリーンショットを撮り目視。「弐瓶らしいか(豆粒感・厚み・闇の落差・非反復)」を品質ゲートに。

## エラー処理

- 未知のバイオーム/高度は末尾バイオームでクランプ(既存踏襲)。
- ズーム計算は範囲外入力をクランプし、常に有限値を返す。

## スコープ外(YAGNI)

- 音。
- セーフガードAIの新規実装、敵/戦闘。
- 物語・断章テキスト。
- 実CC0タイル素材(Kenney等)の導入(差し替え口は既存のまま維持)。
- カメラ追従消失点の動的押し出し(段階3のスクショ判断で後付け検討)。
- 断面インテリア透視・白い虚空といった路線の全面変更。

## リスクと留意

- **奥行きと可読性の両立**: 後退内面を濃くしすぎると足場が読めなくなる。段階3で明バイオーム/狭通路のスクショを必ず確認し、内面の濃さ・幅をバイオーム連動で抑える。
- **ズームアウト時の描画コスト**: 横90+タイルで可視チャンク数が増える。焼き込み drawImage は拡縮のみなので許容想定だが、段階1でフレーム時間を計測。
- **worldgen 尺度変更の波及**: 到達可能性とスポーンに影響。段階1で到達性テストを先に更新してから尺度を広げる(手戻り防止)。
- **累積構造の性能**: 装飾/バリアントの増量は焼き込み時のみ。1チャンク数ms以内を維持。
