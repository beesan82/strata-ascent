# 設計: 段階3-B — ロストと遺留品拡張／貴重品と確保額（2026-11-10）

段階3（エクストラクション化）の第2弾。確定済みの判断（ドラフト推奨どおり）に従う:

- ロストは中間案: **未確保の携行品は死亡で遺留品になり、回収に戻れる**。確保済みは失わない。
- 通貨は作らない。貴重品は「確保額」という記録のためだけに存在する。

## 1. ロスト（遺留品の拡張）

- 死亡時、携行中（未確保）の全アイテム — 素材・砲弾・パルス弾セル、そして新種の貴重品 — を、既存の遺留品の仕組み（最後に安定して接地していた場所、最大 2 か所、古いものから消える）へ落とす。糧食の遺留品は従来どおり同じ箇所に混ざる。
- 携行カウントは 0 になる。保管済み（確保済み）は一切減らない。装填中のパルス残弾が 0 になる現行規則はそのまま。
- 落とし方は既存の `dropRemainsOnDeath` の拡張とし、地面ドロップとして実体を置く（拾えば携行へ戻る既存経路をそのまま使う。携行が満杯なら地面に残る）。

## 2. 貴重品（新種）

- 携行種別に `valuable`（貴重品）を追加する。枠は他の種別と共有。用途は持って帰ることだけ（消費・使用はできない）。
- 入手先（初期値、調整可）:
  - 通常敵のドロップ抽選に低確率（目安 2%）で混ぜる。地区倍率は既存の仕組みに乗せる。
  - ボス「広間番人」の報酬に 1 個を確定で追加する。
  - 補給キャッシュに低確率（目安 5%）で混ぜる。
- 地面ドロップ種別にも `valuable` を追加し、携行との対応付け（carryKindFor / dropKindFor）をそろえる。取得ログの表示名は「貴重品」。

## 3. 確保と確保額

- 貴重品は素材と一緒に**自動確保**の対象とする（休憩点の箱に入った瞬間に素材と貴重品が確保される。弾薬の手動保管は従来どおり）。
- **確保額 = 確保済みの貴重品の個数 × 500**（導出値として持つ。引き出せば下がる。別カウンタで累積しない）。
- 表示:
  - アイテムボックスの状態セクションに「確保額」を出す。
  - 確保時の字幕に、貴重品が含まれる場合はその額が分かるようにする（既存の確保字幕の流儀に合わせる）。
  - アイテムボックスの携行セル・保管チップに貴重品の見た目（金色の ◆ 系）を出す。

## バージョン

2.11 とする。

## やらないこと

- 永続化（段階 D の判断までセッション内のみ）。
- 貴重品の売却・通貨化・ショップ。
- 強化（段階 C）。
- 遺留品の箇所数・落下位置の規則変更。
