# 高精細ピクセルパイプライン 設計書

## 背景

段Iで導入した内部低解像度バッファは、1280px幅の画面で内部幅が約213px、1タイルが約6内部ピクセルになる。ドット感は明確だが、`BLAME!`らしい巨大構造体の梁、配管、足場、遠景の階層が強いディザへ埋没し、重厚さよりレトロゲームらしさが前に出ている。

本改修では、画角やゲームロジックを変えず、内部解像度、固定パレット、ディザ強度を高精細表現向けに再調整する。

## ゴール

- 34タイルの画角を維持しながら、1タイルあたり約12内部ピクセルを確保する。
- 細い梁や配管を最低1〜2内部ピクセルで残す。
- 大空洞で前景、中景、遠景の構造を識別できるようにする。
- ピクセルの輪郭と限定パレットの統一感を保つ。
- 物理、ワールド生成、破壊、入力、ゲーム進行には影響を与えない。

## 採用方針

既存の `PixelPipeline` を高解像度化する。レイヤー別バッファや構造物の全面描き直しは行わない。

- 内部目標幅: `34 tiles × 12 px = 408px`級
- 1280px幅での想定内部幅: 約426px
- 整数拡大率: 約3倍
- 固定パレット: 32色
- ディザ強度: 12を初期値とし、8〜16の範囲でスクリーンショット調整
- 画角: 34タイルを維持
- ズーム段: `0.5 / 0.75 / 1`を維持
- 拡大方式: nearest-neighborの整数倍表示

## 32色パレット

32色は以下の役割に分ける。

- 寒色鋼ランプ28色
  - 最暗部4色
  - 暗部8色
  - 中間階調10色
  - 明部・縁光6色
- 暖色アクセント4色
  - 暗い錆
  - 明るい錆
  - 稼働灯
  - 高輝度灯

寒色鋼ランプは輝度が単調増加する固定値とする。暖色は錆と稼働灯に限定し、無彩色の構造体へ暖色が無制限に混入しないようにする。

最近傍色の選択方式は既存の知覚重み付きRGB距離を維持する。動的パレット生成やシーンごとの適応量子化は使用せず、シードやフレーム間で色が揺れない決定論を守る。

## ディザ

4×4 Bayerディザは維持するが、強度を32から12前後へ下げる。

ディザの役割はグラデーションの色帯を散らすことに限定する。構造物の面全体を市松模様で覆う状態は不合格とする。最暗部でも構造の輪郭がディザより優先して読めることを目視ゲートに含める。

## 解像度と表示

`PixelPipeline`へ渡す1タイルあたりの内部ピクセル数を6から12へ変更する。既存のリサイズ計算により、画面幅に応じて整数拡大率と内部バッファ寸法を決定する。

画面への転写は以下を維持する。

- `imageSmoothingEnabled = false`
- 整数倍のnearest-neighbor拡大
- 余り領域は最暗色でレターボックス表示
- カメラと画面シェイクは内部ピクセル単位へスナップ

極端に小さいウィンドウでは拡大率1を許容する。この場合も量子化は有効だが、整数拡大によるドット強調は行われない。

## データフロー

1. 既存レイヤーを約426px幅の内部canvasへ描画する。
2. 画素を32色固定パレットへ量子化する。
3. 弱いBayerディザで色帯だけを分散する。
4. 画面canvasへ整数倍で拡大転写する。

ワールド座標、当たり判定、破壊差分には触れない。

## テスト

### 自動テスト

- パレットが32色で重複しない。
- 先頭28色の輝度が単調増加する。
- 暖色アクセントが4色に限定される。
- 全パレット色が自身の添字へ量子化される。
- `quantizeRgba`の出力が必ず32色パレット内に収まる。
- アルファ保持、決定論、Bayer周期の既存テストを維持する。
- 全既存テスト、型チェック、production buildを通す。

### スクリーンショットゲート

spawn、中層、大空洞、水系統を1280×720で撮影し、以下を確認する。

- 梁、配管、足場の細線が残る。
- 前景、中景、遠景の層を識別できる。
- 面全体が強い市松模様にならない。
- 錆と稼働灯の暖色が残る。
- HUDが読みやすい。
- 移動、離散ズーム、画面シェイクでドットグリッドが破綻しない。

## スコープ外

- タイルや構造物をネイティブなピクセル素材へ全面的に描き直すこと。
- レイヤーごとに別のパレットや量子化強度を適用すること。
- ライティングモデル、施設配置、ワールド生成の変更。
- 32色を超える動的パレットやフルカラー表示。

## 完了条件

- 32色固定パレットと弱いディザが実装されている。
- 1280px幅で内部幅が約400〜430pxになる。
- スクリーンショットゲートを満たす。
- `npm test`、`npx tsc --noEmit`、`npm run build`が成功する。
