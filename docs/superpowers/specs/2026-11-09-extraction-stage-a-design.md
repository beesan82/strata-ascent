# 設計書: サバイバル刷新（エクストラクション化）と段階 A（2026-11-09）

## 全体の方向（判断はドラフトの推奨どおりで確定）

ドラフト `~/workspace/strata-stage3-design/draft-design.md` の判断ポイント 8 件は、佐事の「次に行こう」を受けて推奨どおりで進める:

1. 永続化: 段階 A〜C はセッション内のみ。永続化は段階 D で改めて判断。ただしデータ形は保存可能な形（種別と個数だけ）に寄せる
2. インベントリ: 携行枠＋種別スタック（総個数制限）。グリッド・重量制は不採用
3. ロスト: 中間案。未確保分は遺留品化して回収可能、確保済みと取り付け済み強化は失わない（段階 B で実装）
4. 確保の成立: どの休憩点に着いても確保（前進・後退どちらでも）
5. 強化: 携行枠・満腹度上限を主役に、砲の弾数・HP は各 1 段階まで（段階 C で実装）
6. 通貨: 作らない。貴重品は「確保額」の記録のみ（段階 B で実装）
7. 地区固有素材: 共通素材 1 種で始め、地区固有は段階 C で追加
8. ロードアウト: 無し（消耗品は現地調達のみ）

実装は段階 A〜D に分け、各段階が単独で遊べる形にする。本設計書は段階 A を規定し、B 以降は各段階の開始時に別途設計を起こす。

## 段階 A の範囲: 「持って帰る」だけ

問いは 1 つだけ: **拾った物を休憩点まで持って帰る行為自体に手応えがあるか**。ロストも強化も無い。

### 素材アイテム

- 共通素材 1 種「素材セル」（仮称。表示名は実装時に世界観へ寄せる）。既存 3 種（砲弾＝紫、回復＝緑、糧食＝金）と混同しない色と形を 32 色パレットから選ぶ。
- 入手は既存経路への相乗り: 敵ドロップ抽選（`dropFor`）へ素材の抽選を混ぜる、補給キャッシュの中身（`supplyFor`）へ素材を混ぜる。確率は既存の重み方式・合計圧縮の枠組みの中で調整し、消耗品の出現を大きくは崩さない。
- 地面での扱いは補給品区分に寄せる（寿命なし、上限は既存の補給品プールの枠内）。決定論の抽選を維持する。

### 携行枠

- 携行枠は素材の総個数で数える（消耗品の即時消費と糧食所持は現行どおり枠外）。
- 初期値は 5 個。満杯のときは現行の `canPickup` と同じく拾えずに地面に残る。
- 将来の段階で他の携行品（貴重品・装備）が加わる前提で、所持の構造は「種別ごとの個数」で持つ。

### 確保

- 休憩点の箱に入ったとき（復活点が更新される安全圏への到達時）、携行中の素材がすべて「確保済み」へ移り、携行は 0 に戻る。
- 確保はセッション内の数として数える（永続化しない）。最深記録と同じく HUD に併記する: 携行 n/5、確保済み m。
- 確保の瞬間には合図を出す（既存の休憩点の音か、確保専用の短い合図を既存の音系に相乗りさせるかは実装裁定）。

### やらないこと（段階 A）

- 死亡時のロスト・遺留品の拡張（段階 B）。段階 A では死亡しても携行素材はそのまま保持される（まず「持って帰る」だけを検証するため）。
- 貴重品・確保額（段階 B）、強化（段階 C）、地区固有素材・レアリティ（段階 C）、永続化（段階 D）。
- 新しいボタン・メニュー・画面。拾う・確保はすべて接触と自動処理。

## 受け入れ基準

- 素材の出現・携行・確保が純粋関数の単体テストで固定される（抽選の決定論、枠の上限、確保の遷移）。
- HUD に携行と確保が表示され、休憩点到達で携行が確保へ移る。
- `npm test` / `tsc` / `build` 全通過。frametime の render p50 悪化 +0.5ms 以内。描画パスは増やさない。
- MARKETING_VERSION を 2.4 に上げる。
