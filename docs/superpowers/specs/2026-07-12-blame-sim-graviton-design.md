# 重力子放射線射出装置 設計書

日付: 2026-07-12
ステータス: 承認済み
前提: 超構造体アーク(段階1-5)完成後の、最初のゲームプレイ機能

## 背景と決定

Blame!の霧亥の切り札「重力子放射線射出装置」を撃てるようにする。当初のゲーム設計書(2026-07-11)で構想していた武器。世界が階層生成に変わり敵はまだ存在しないため、対象は地形破壊(=全段階で「詰み防止の最終手段」として言及してきた役割)。

決定事項:
- **威力**: 巨大な穴を長距離。マウス方向へ数百タイル貫通する太いビームで通路をこじ開ける
- **弾数**: チャージ制(最大3発)+時間で自動回復
- **破壊**: 永続的(破壊差分を保持)。リロードで消える(セーブしない)

## 武器の挙動

- **狙い**: マウス方向(既存のライト照準と同じ)。プレイヤー中心からマウスへの直線
- **発射**: 発射キー(KeyF またはマウス左)を約0.6秒長押ししてチャージ(銃口に光が溜まる)→ 離すと発射。溜め中も移動可だが telegraph される
- **弾数**: 最大3発のプール。発射で1消費。時間で自動回復(1発あたり約6秒)。0発だとチャージ不可
- **ビーム**: 発射時に判定するヒットスキャン直線(飛翔時間なし)。マウス方向へ長距離(約300タイル、またはロード範囲端まで)。太い(幅5〜7タイル)。経路上の SOLID/LADDER をすべて AIR へ破壊し貫通(壁・施設・メガ施設も貫く)
- **破壊の永続**: 破壊差分マップに記録し、`tileAt` 合成の最優先で AIR を返す。チャンク再生成後も穴は残る。セーブなし
- **演出**: 白い太いビームのフラッシュ(数フレーム)+銃口閃光+軽い画面シェイク

## アーキテクチャ

破壊は読み取り専用生成への唯一の差分レイヤー。合成順の最優先に差し込む。

```
src/world/
  destruction.ts   — 破壊差分ストア(新規)。破壊タイルの Set を保持。
                     bore(x0,y0,angle,length,radius): 直線+半径上の非AIRタイルをAIR化して記録。
                     isDestroyed(x,y) を提供。純粋データ+操作(ユニットテスト対象)
  worldgen.ts      — tileAt 合成の最優先に破壊チェック(梯子保持より前)。
                     tileAt の純粋性を保つため、破壊込み経路は別関数(下記「純粋性」参照)
src/entities/
  graviton.ts      — 重力子砲の状態機械(新規)。弾数・チャージ・自動回復を保持。
                     update(dt,input) でチャージ/発射判定、fire で bore を呼ぶ。lastBeam を保持。純粋ロジック(テスト対象)
src/core/input.ts  — 発射キー(KeyF/マウス左)を state に追加
src/render/
  beam.ts          — ビームフラッシュ+銃口閃光の描画(新規、演出)
  renderer.ts      — beam 描画・チャージグロー・画面シェイクを合成
src/main.ts        — graviton 生成、update 結線、HUD弾数表示、destruction を ChunkStore/tileAt と共有、破壊時のチャンク焼き直し無効化
```

**データフロー(発射)**: 入力(長押し→離す) → graviton.update がチャージ完了検知 → プレイヤー中心+マウス方向から destruction.bore(px,py,angle,length,radius) → 経路上の非AIRタイルを破壊集合へ → 以後 tileAt がそこを AIR で返す → 該当チャンクを焼き直して穴を反映 → ビーム演出を数フレーム描画。

## tileAt の純粋性を保ちつつ破壊を差し込む

既存 `tileAt(seed,x,y)`(純粋・決定論)はワールド生成テストの土台なので署名・挙動を保つ。破壊は「注入された destruction ストア」を見る別経路にする:
- `tileAt(seed,x,y)` は従来通り生成専用(破壊を見ない)。既存テスト回帰なし
- 実描画・物理が使う経路を `tileAtLive(seed,x,y)` とし、`if (destruction.isDestroyed(x,y)) return TILE.AIR; return tileAt(seed,x,y);`
- `ChunkStore`/`generateChunk`/`findSpawn` が使うのは live 経路。destruction ストアは main で生成し ChunkStore へ注入
- destruction が空なら tileAtLive ≡ tileAt(回帰なしの担保)

破壊集合はワールドタイル座標の Set(`"x,y"`)。bore は length×radius に比例する有限タイルのみ触る。破壊時は該当チャンクをキャッシュ無効化して焼き直す。

## テスト方針

- ユニット(Vitest):
  - destruction: bore が直線+半径範囲の非AIRを破壊集合へ入れる / isDestroyed 整合 / 決定論 / 空集合では未破壊
  - graviton: 弾数消費と自動回復(時間で増える、上限3)、0発ではチャージ/発射不可、チャージ完了で fire は1回だけ(長押し連射しない)、離す前は発射しない
  - 合成: 破壊集合の座標は tileAtLive で必ず AIR / 空なら tileAt と完全一致
- ビーム演出・チャージグロー・画面シェイク: スクリーンショット+実プレイ目視

## エラー処理
- ビームは length で打ち切り(無限ループ防止)
- bore の破壊数は length×radius に比例する有限数のみ

## 段階分け
1. **破壊ストア** — destruction.ts + tileAtLive 差し込み。ユニットで「破壊座標は AIR / 空なら不変」。まだ撃てない
2. **重力子砲ロジック** — graviton.ts(弾数・チャージ・発射→bore)+ input 発射キー。ユニットでチャージ/弾数/回復
3. **統合と演出** — main 結線、チャンク焼き直し無効化、ビーム/銃口グロー/画面シェイク、HUD弾数。実プレイで「撃つと巨大な穴が長距離に空き跡が残る」を目視

## スコープ外
- 敵・当たり(敵はまだ存在しない。ビームは地形のみ破壊)
- セーブ/localStorage(破壊はリロードで消える)
- 弾薬アイテム・充電端子(自動回復のみ)
- 音

## 留意
- 破壊は tileAt 合成の最優先なので、ノイズ梯子・施設・メガ施設すべてを破壊できる=詰み防止の最終手段が成立
- 物理は無改修。破壊で足場が消えれば落下する(意図通り)
- tileAt(純粋)と tileAtLive(破壊込み)を分離し、既存の決定論テストを守る
