# 設計書: エイム専用スティック(ツインスティック化)

状態: ユーザー承認済み(2026-11-03、「エイムの向きが変えられない」への 2 案提示で
「右側にエイム専用スティックを追加」を選択)

## 背景

タッチ操作では照準を「プレイヤーの向きの水平」に固定していた(タッチ照準は従来非ゴール)。
実機で遊んだユーザーから「エイムの向きが変えられない」と指摘があり、ツインスティック方式にする。

## 方式

- 画面を左右に分け、**左半分 = 移動スティック**(現行の浮動スティック)、
  **右半分 = エイムスティック**(新規の浮動スティック)とする。見た目は同じ土台円+ノブ。
- エイムスティック:
  - 倒した方向(単位ベクトル)を照準にする。デッドゾーンは変位 18px。
  - 倒している間は **自動で発射** する(KeyF を押しっぱなし扱い)。離せば照準は
    「向きの水平」に戻り、発射も止まる。
  - 砲ボタンは残す(スティック無しで真横に撃つ従来操作もできる)。発射キーは
    ボタンとスティックの OR で管理し、片方を離してももう片方が押していれば撃ち続ける。
- 照準の配線: `Input` にタッチ照準(単位ベクトル + 有効フラグ)の入口を足し、
  `main.ts` はマウス未使用時にそれを使って照準用の合成マウス位置と viewState の
  aimX/aimY を作る。合成位置は現行の水平フォールバックと同じ「中心 + 方向 × 画面の 1/4」
  方式(プレイヤーが中心付近にいる前提の近似で、現行方式と同程度の誤差)。

## 非ゴール

- エイムの感度設定、アナログの強弱での威力変化。
- PC(マウス)操作の変更。

## 検証

- 純粋関数 `aimStickState(dx, dy)`(デッドゾーン・正規化)と Input の照準入口を Vitest で固定。
- エミュレーションで 2 本指同時タッチ(左で移動、右上へエイム)を再現し、斜め上へ
  ビームが出る/弾数が減ることを確認する。
- PC 開始地点は差分 0。
