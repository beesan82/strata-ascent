# 意味のある超構造体: 階層的ワールド生成 設計書

日付: 2026-07-12
ステータス: 承認済み
前提: ビジュアル刷新(SM級ルック)完了後の、ワールド生成の意味づけ再設計

## 背景と決定

プレイテストで「構造体に意味がなく、散歩しても面白くない」との評価。原因は、世界がノイズの塊で、場所に機能・因果・多様性がないこと。方針を以下に決定:

- **求めるもの**: ゲーム機構(敵/目的/能力)ではなく、**構造体そのものに機能的な意味と因果**を持たせる。「貯水池のそばに配管」「発電所から電線が伸びる」のように、配置に理由が見える設計された機械都市にする。
- **施設**: 入れる部屋+つながる配管(ランドマークや配管だけでなく、中に入れて機能が分かる部屋)。
- **生成の土台**: 施設中心に再設計(案A: 階層グリッドのトップダウン解決)。
- **スケール**: 超構造体を圧倒的スケールで。4階層以上の入れ子。無限・決定論・チャンク局所。
- **多様性**: 各階層に大量のランダム要素を入れ、探索の楽しみ(毎回違う・未知との遭遇)を出す。決定論は保つ(再訪の一貫性)。

トレードオフ: 今までで最大の変更。ノイズ主導の生成を階層主導へ作り直す。ゲームの地形(当たり判定)が変わるため、物理コードは無改修だが到達可能性のテストとspawnは更新する。

## 生成アーキテクチャ(案A: 階層グリッド)

`tileAt(seed, x, y)` を上位階層から解決する。すべて2次元セル格子(横移動でも上昇でも別セクター/地域へ入る)。各セルの性質は `hash(seed, cellX, cellY, level)` で決定論的に決まる。あるタイルは各階層で「自分のセル+近傍1セル」を見れば所属が確定するため、チャンク局所・無限・継ぎ目なしを保つ。

### 階層とスケール(1タイル≒1m、チャンク=64タイル)

| 階層 | サイズ | 内容 |
|---|---|---|
| 部屋(room) | 24〜128タイル | 入れる1施設。型ごとの内部レイアウト |
| 地区(district) | 1,024タイル(16チャンク) | 施設複合。数個の部屋+ローカル配管。機能はセクターに従う |
| セクター(sector) | 16,384タイル(256チャンク) | メガ施設1系統。幹線ハブ。遠景に巨大シルエット |
| マクロ地域(region) | 262,144タイル(≈256km、4096チャンク) | 支配系統を決め、配色と全体の性格を与える |

- 5階層目(超地域)は生成規則上は足せる余地を残すが、初期は4階層。
- 見た目の性格(バイオーム/配色)の選択を**高度ベースから地域ベース(2次元)へ移す**。既存 `biome.ts` のパレット定義は流用し、選択ロジックのみ地域に差し替え。高度は「素の躯体密度」に引き続き影響。

## 施設と因果

マクロ地域ごとに支配系統(system)が1つ決まる。系統がセクター/地区/部屋の施設タイプ集合と配色を規定する。

| 系統 | メガ施設(セクター級) | 施設(部屋級) | 主要ネットワーク |
|---|---|---|---|
| 水 | 巨大貯水池 | ポンプ室、濾過槽、貯水タンク | 太い配管(水) |
| 電力 | 発電炉 | 変電室、蓄電室、制御室 | 電線・バスダクト |
| 居住 | 居住コア | 居室ブロック跡、通路、広間 | 給水管+電線(消費側) |
| 廃棄 | 廃棄立坑 | 圧縮機室、集積庫 | 排出ダクト |
| 精錬 | 精錬炉 | 溶鉱室、鋳造室 | 高温配管+電力 |

### 因果(最重要)
ネットワークは「源→消費」の関係で引かれ、生成規則として実際に接続する(装飾ではない):
- 発電系統の発電炉から電線が隣接セクターへ伸び、居住/精錬の消費施設に接続
- 水系統の貯水池から配管がポンプ室→各地区の消費点へ分岐
- 「電線をたどると発電炉」「配管の先に貯水池」が成立する

### 部屋の中身(入れる)
各施設タイプは決定論的な内部レイアウトを持つ:
- 貯水タンク = 大空洞+底に水面表現+側壁キャットウォークと梯子+太い取水/排水管が壁を貫く
- タービン室 = 中央の巨大ローター輪郭+周囲の点検通路+バスダクトが天井を走る
- ポンプ室 = 並ぶポンプ筐体+バルブ+入出力配管が両側の壁へ

部屋は必ず入口開口を持ち、隣接する通路/経路に接続。

## 多様性と発見(各階層のランダム要素、すべて決定論)

- **部屋**: 寸法(範囲内)、内部要素配置、左右反転、崩壊度(無傷〜半壊〜瓦礫)、稀な異常(水没・焼損)。同型でも二つと同じものがない。
- **地区**: 施設の種類/数/並び、連結の取り回し、密度、状態(稼働/廃墟/封鎖)。
- **セクター**: メガ施設のシルエット形状・規模・ハブ位置・幹線方向、稼働/死亡地区の比率。
- **マクロ地域**: 支配系統+副系統の混入、境界の混ざり方。
- **稀少要素(発見の報酬)**: 低確率で桁違いに巨大な構造/異質な構造/人工ランドマークが出現。頻度はセクター/地域ハッシュで制御。
- **原則**: 範囲パラメータ(min〜max を hash 抽選)+ 重み付き選択テーブル + 崩壊/変異レイヤー の3本柱でテンプレ感を消す。

## ネットワークの決定論的経路
- 各セルは近傍セルとの接続を順不同ペアのハッシュ `hash(seed, min(A,B), max(A,B))` で決め、両端が同一の経路多項式を得る(どちらのチャンクから引いても同じ)。
- 経路は粗いL字/階段折れ+ハッシュ揺らぎの折れ線。太さは階層で決まる(セクター間=極太トランク、地区間=枝、部屋内=細管)。
- あるタイルは「自セル+近傍1セルの接続集合」で経路上か判定(チャンク局所維持)。

## 到達可能性の保証(ゲームを壊さない)
- ネットワーク経路には必ずキャットウォーク+梯子/昇降シャフトが併走。幹線は垂直の大昇降路を含む。
- 部屋は必ず入口開口を持ち経路/通路へ接続。
- 生成の最後に「上方向ルートの存在」をセクター単位で保証(既存の梯子=常時存在ルールを骨格に統合)。詰み防止の最終手段(重力子砲=地形破壊)は将来段階のまま。
- `findSpawn` を施設の安全な床点に更新。

## 既存システムとの統合
- `tileAt` を階層解決に差し替え: 部屋/経路判定を最優先、外れたら従来ノイズが「素の躯体」を埋める。物理(`physics.ts`)は無改修。
- 描画(オートタイル/バイオーム/パララックス)はほぼ再利用。バイオーム選択を高度→地域へ差し替え。遠景パララックスにセクターのメガ施設シルエットを反映。
- `chunks.ts`(キャッシュ/破棄)は流用。`decor` の配管・電線アクセントを施設/経路に紐付けて意味づけ。

## テスト方針
- ユニット(Vitest): 階層セル解決の決定論写像、ネットワーク経路の両端一致(A→B == B→A)、到達可能性(生成セクターに上方向ルートが存在)、`tileAt`決定論、施設の入口存在。既存テストは回帰なし維持。
- 見た目/歩き心地: スクリーンショット+実プレイ目視(施設が「場所」として読めるか、配管をたどると源に着くか)。

## 段階分け(各段階が動く縦スライス)
1. **階層の骨格** — region/sector/district/room のセル解決+決定論テスト。見た目は素のノイズ+デバッグ可視化。
2. **入れる施設1種(貯水池)** — 部屋レイアウト+多様性(範囲/崩壊)。ノイズ躯体に施設が埋まる。到達可能性保証。
3. **ネットワーク** — 配管/電線が経路上に生成、キャットウォーク併走、両端一致。因果の骨格。
4. **系統と因果** — 複数施設タイプ+セクター幹線+源→消費接続(発電→電線→ポンプ)。地域バイオーム化。
5. **圧倒的スケールと発見** — セクター遠景シルエット、稀少ランドマーク、多様性チューニング、総合調整。

各段階は独立した実装計画(spec→plan→実装)とし、段階ごとにレビューとスクショ確認を行う。

## スコープ外
- ゲーム機構(敵/戦闘/目的/能力/資源)。今回は構造の意味づけに集中。
- 音。
- 水/電力の実シミュレーション(見た目上の因果のみ。流量計算などはしない)。
- 実CC0タイル素材の導入(差し替え口は既存)。

## リスクと留意
- 最大の技術リスクは「無限・決定論・チャンク局所で長距離接続と到達可能性を両立」。近傍1セル参照+順不同ペアハッシュで解けるが、経路が近傍セルを越えて曲がる設計にすると局所性が崩れるため、経路は近傍セル内で完結する折れ方に制約する。
- 生成コスト: 階層解決が `tileAt` ごとに走るので、上位セルの性質はメモ化(セル座標キー)して1タイルあたりの計算を抑える。
- 段階1で決定論・局所性・到達可能性の骨格を固めてから見た目に進む(手戻り防止)。
