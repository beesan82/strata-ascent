# 弐瓶勉らしい絵作り(視覚リアリティ)設計書

日付: 2026-07-17
ステータス: 承認済み(ユーザーレビュー待ち)
前提: `nihei-essence` 設計(2026-07-12)の後継・具体化。プレイテストで「グラフィックが弐瓶勉の世界観を堪能できる水準に達していない」が最大の問題と判断された。

## 背景と決定

`supermetroid-look` 転換で得た可読性の代償に、①均一タイル格子が「整ったゲームの壁紙」に見える ②建築的奥行き(Z軸)が無い平面 ③空洞が"空虚な黒"で圧倒しない、という状態になっていた。ビジュアル・ブレインストーミング(モック反復)で以下を確定した:

- **方向性(承認済み)**: 闇を「空虚」ではなく「消失点へ後退する**意味を持つ巨大機械**のシルエット」で充満させる。人は豆粒。抽象的なシルエットは不採用。
- **意味のある機械**: 既存の系統(水系/電力系/居住区/廃棄区/精錬区。`hierarchy.ts` の `regionAt().system`)に対応した機械を配置し、今いる系統の機械が闇の奥に立ち上がる。
- **リアリティの定義(5原則)**: ①明度4段の階調(遠=ほぼ黒/中=暗灰/近=中灰/光の当たる上端=明) ②一貫した光と落ち影 ③荷重を支える接合(ガセット・ボルト列・溶接跡・H鋼フランジ) ④形に沿った風化(ボルト/エッジから下へ流れる錆・汚れ) ⑤グリーブルの3階層(大=躯体→中=配管・ケーブルトレイ→小=ボルト・リベット)。
- **損傷は連続ランダム**: 「健全/崩壊」の離散状態ではなく、`damage`(0〜1)を**シード＋ワールド座標で決定論的**に決める。軽微な錆びから半壊(骨組み露出・天井陥没・瓦礫)まで無段階。基調は「経年・損傷」。
- **移動環境も弐瓶化**: 歩く・登る足場も背景と地続きのブルータリズム(鋼グレーチング床/コンクリ壁+リブ柱/後退内面/ケージ梯子/壁↔床を横断する配管)。ただし**歩ける上面は必ず明リムライトで可読性を死守**し、崩れ・奥行きは下面と背後へ逃がす。
- **人がいた痕跡**: 遺体(骨)・落とした携行ライト・荷袋・空薬莢・壁の日数刻み・消えかけた警告。環境で物語る。将来の断章テキスト接続口とする(当初設計の物語ピラーへの橋渡し)。

### 採用した強化レバー

| レバー | 採否 | 適用 |
|---|---|---|
| カメラ開閉ズーム(豆粒化) | 採用 | 背景スケール大の開放空間で引き、屋内など閉塞で寄せ。開放度で連続追従 |
| 大気遠近(かすみ) | 採用 | 常時。遠い構造は暗くするのでなくコントラストを灰の靄へ溶かし、無限の奥行きを出す |
| 硬い光条(体積光) | 採用(**場所依存**) | 高所開口のある空洞など条件を満たすスロットのみ。埃を照らし床に光溜まりを落とす |
| バイオメカニカル異物 | 採用(稀) | 椎骨状の有機-機械柱が正規構造を突き破り内部に脈光。異質さ・崇高 |
| 超巨大ランドマーク | 採用 | 都市大の構造がかすみの奥にそびえ、頂部に明滅する標識灯。遠くから見える航路の目印 |

### トレードオフ(承認済み)

- 描画層・カメラ・(移動環境の見た目としての)worldgen尺度に集中する。**`physics.ts` は無改修**。背景超構造・痕跡・光条・ランドマークは**非衝突**。移動環境は見た目のみ変え、**当たり判定は矩形のまま**。
- カメラ追従の"本物の消失点"(可視タイルの動的押し出し)は初期スコープ外。固定方向の後退内面＋パララックス＋かすみで擬似的に作る。
- すべての生成は**決定論的**(同一シード＋座標→同一出力)。セーブは従来どおりシード＋差分で足りる。

## モジュール別設計

既存 `src/render/` の分割流儀(`tileset/` サブフォルダ、純粋関数を切り出しユニットテスト)に倣う。純粋関数は責務を「判断・幾何生成」に限り、Canvas 描画と分離する。

### 0. カメラ開閉ズーム — `core/zoom.ts`(新) / `core/camera.ts`

`core/zoom.ts`(純粋関数):
- `sampleOpenness(tileAt, cx, cy, r, step) → 0..1`: プレイヤー周囲の非SOLID割合(AIR/LADDER=開放)。破壊反映済みの `store.tileAt` を渡す。
- `targetZoomForOpenness(openness) → zoom`: 開放度→目標ズーム。閉塞(`OPENNESS_LO`以下)=標準、十分開放(`OPENNESS_HI`以上)=最大ズームアウト、間は線形。範囲外は `[MIN_ZOOM, MAX_ZOOM]` にクランプ。

`core/camera.ts`: `zoom` フィールド＋指数平滑 `zoomTo(target, dt)`(位置追従より緩やかにして酔い防止)。`main` が毎数フレーム開放度→目標ズームを計算し `camera.zoomTo` に渡す。`renderer` は `ppt` に `cam.zoom` を乗じる(全レイヤーが `ppt` 経由で自動追従)。

> 既存 [nihei段階1計画](../plans/2026-07-12-blame-sim-nihei-stage1-zoom.md) がこの内容を網羅済み。段階Aはこれを流用する。開閉の"寄せ"側は `OPENNESS_LO` 以下で `MAX_ZOOM` に戻る既存挙動がそのまま満たす。

### 1. 背景の意味を持つ超構造 — `render/megastructure/`(新)

- `catalog.ts`(純粋): `buildStructure(type, damage, rng) → StructureSpec`。`StructureSpec` は層別(遠/中/近)のポリゴン・配管パス・グリーブル矩形群・欠損矩形・露出フレーム線・リムライトエッジ・稼働灯/熱光の点群。5系統の型を持つ:
  - `power`: 球形格納容器・タービンホール(縦配管束)・変圧器バンク＋母線
  - `water`: 冷却塔(双曲線)・巨大貯水槽・水管橋
  - `foundry`: 溶鉱炉(内部に硬い熱光)・取鍋クレーン・煙突
  - `disposal`: 焼却炉・巨大排気ダクト(蛇行)・廃棄ピット
  - `habitation`: 蜂の巣状の居室セル(規則→崩壊)
  - `damage`(0..1)がパネル欠損率・汚れ筋・垂れ配管・エッジ欠け・骨組み露出・瓦礫量を単調に駆動。稼働灯は低`damage`のみ。
- `place.ts`(純粋): `slotsInView(cam, w, h, seed) → Slot[]`。構造スロット格子(数百タイル級間隔)を可視範囲で列挙し、各スロットに `type`(その座標の `regionAt().system`)・`damage`(座標hash＋高度が上がるほど崩壊寄りのバイアス、クランプ)・視差深度・変種seedを決定論的に付与。
- `megastructure.ts`: `render(ctx, cam, w, h, ppt, bb, slots)`。深度ごとに `catalog` のスペックを描画。**奥ほど暗く純黒へ**、かつ後述のかすみで**灰へ持ち上げ低コントラスト化**。上端エッジのみリムライト。視差追従率は深度で変える。

### 2. 大気遠近(かすみ) — `render/megastructure.ts` 内 / `render/atmosphere.ts`(新・小)

深度バンドごとに、構造の値を「暗く」ではなく **かすみ色(`bb.ambientColor` 由来の脱彩度した青灰)へ寄せて低コントラスト化**する。実装は深度に応じたベール(半透明フィル)を層間に敷く+遠層の基準明度を持ち上げる。近層はクリスプに純黒＋強リムライト。純粋部分(深度→かすみ係数)を切り出しテスト。

### 3. 移動環境の弐瓶化 — `render/chunkbake.ts` / `render/tileset/generate.ts` 改

焼き込み時のみ処理(実行時コストは据え置き)。
- **床**: 鋼グレーチング/厚いスラブ。歩ける上面に**明リムライト**(可読性の不変条件)。下面は厚み＋吊り配管・ブラケットで奥行き(後退内面)。
- **壁**: コンクリ＋リブ柱＋抜けパネル＋露出鉄筋。**ワールド座標ハッシュで連続損傷**(背景と同じ`damage`思想)。均一格子感を壊す多重継ぎ目。
- **梯子**: ケージ付き工業ラダー。
- **配管**: 壁↔床を横断し背景機械と地続きに見せる。
- **後退内面(押し出し幾何)**: 空気に面したSOLIDエッジから奥へ後退する暗い内面帯。押し出しジオメトリ(エッジ→台形頂点)は**純粋関数**として切り出しテスト。押し出しはタイルローカル固定方向。
- **可読性ゲート**: 明バイオーム/狭通路のスクショで足場が読めるか必ず確認。内面の濃さ・幅はバイオーム連動で抑える。

### 4. 人の痕跡 — `render/traces.ts`(新)

`placeTraces(cam, w, h, seed) → Trace[]`(純粋・決定論): 低密度で遺体(骨)・携行ライト(消えかけ残光)・荷袋・空薬莢・壁の日数刻み・警告記号を配置。描画は非衝突オーバーレイ(チャンク焼き込みの上、プレイヤーの下)。各 `Trace` は将来 `loreId` を持てる構造にし、当初設計の断章テキスト接続口とする(テキスト自体は本スコープ外)。

### 5. 味付け — `render/lightshaft.ts`(新) / バイオメカ・ランドマークは `catalog.ts`/`place.ts` 拡張

- **光条(場所依存)**: スロットが「高所開口＋十分な開放度」の条件を満たす場合のみ、硬い光条ポリゴン(加算的な淡い白)＋光溜まり＋埃の粒を描く。発生条件は純粋関数でテスト。合成順はライトの後・近景の前。
- **バイオメカ異物**: `catalog.ts` に稀出現の型を追加。`place.ts` が低確率で通常型を置換。
- **超巨大ランドマーク**: `place.ts` が一定間隔で最遠深度に都市大構造を1本立て、かすみの奥にそびえさせる。頂部に明滅標識灯(緩慢アニメ)。

## データフロー(1フレーム)

入力 → プレイヤー/カメラ更新(開放度→`zoomTo`) → 可視範囲を `place.slotsInView`/`placeTraces` に渡す → 各スロットで `type`(`regionAt`)・`damage`(hash＋高度) → `catalog` がスペック生成 → 描画:
背景フィル → 遠景パララックス → **超構造(遠→中＋かすみ＋ランドマーク＋稀バイオメカ)** → 焼き込みチャンク(弐瓶化＋後退内面) → **痕跡** → プレイヤー → ライト → **光条(場所依存)** → 近景オクルーダ → 重力子砲FX → post。`ppt` に `cam.zoom` 乗算で全層追従。

## 段階分け(各段階=遊べる/見られる縦スライス・スクショ確認)

各段階は独立した実装計画(plan)とし、段階ごとにレビューとスクリーンショット確認を品質ゲートにする。

1. **A. カメラ開閉ズーム(豆粒化)** — 独立・効果最大。既存 nihei段階1計画を流用。
2. **B. 背景超構造＋かすみ** — 5系統カタログ・連続損傷・3層深度・大気遠近。豆粒化と相互増幅。
3. **C. 移動環境の弐瓶化** — 床/壁/梯子/後退内面/連続損傷。可読性ゲート必須。
4. **D. 人の痕跡** — 遺体/遺失物/刻み/警告。断章接続口。
5. **E. 味付け** — 光条(場所依存)・バイオメカ異物(稀)・超巨大ランドマーク。

新規実装計画は**段階Bから**起こす(Aは既存計画あり)。

## テスト方針

- **ユニット(Vitest)**: ズーム写像(単調・クランプ)、`camera.zoomTo`(収束)、`catalog` 幾何の決定論(同 type+damage+seed→同スペック)、`place` の決定論と `damage` 値域[0,1]・高度バイアスの単調/クランプ、後退内面の押し出し幾何(エッジ→台形頂点)、かすみ係数(深度→係数の単調)、光条の発生条件、痕跡配置の決定論。既存全テストは回帰なし。
- **無改修の保証**: `physics.ts`・worldgen 到達性テストは不変(移動環境は見た目のみ、当たりは矩形のまま)。万一 worldgen 尺度に触れる段階があれば到達性テストを先に更新。
- **見た目**: 各系統×損傷度×開放/閉塞×明/暗バイオームでスクリーンショット目視。品質ゲート=「豆粒感・厚み・かすみの奥行き・非反復・痕跡・可読性(足場が読めるか)」。

## エラー処理

- 未知の系統/高度は末尾でクランプ(既存踏襲)。
- ズーム・かすみ・`damage` 計算は範囲外入力をクランプし常に有限値を返す。
- 生成の接続保証が万一破れても重力子砲の地形破壊が詰み防止(既存)。
