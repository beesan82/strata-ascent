# フレーム予算の内訳と描画の制約(2026-10-19 時点)

GPU のない環境で動く前提なので、性能は Playwright の headless 既定(SwiftShader = ソフトウェア描画)で測る。
内部バッファ 427×240 を毎フレーム getImageData → 32 色量子化 → putImageData → 整数倍で画面へ転写する。
予算は 16.7 ms/フレーム(60 fps)。

## 計測の仕方

```powershell
node scripts/frametime.mjs --seed=20260711 --stages                          # 開始地点
node scripts/frametime.mjs --seed=20260711 --pos=244,66 --press=KeyA --stages # 歩行(最悪に近い)
node scripts/frametime.mjs --seed=20260711 --pos=40,60 --stages               # 水系
```

- `render` = `renderer.render` 全体、`present` = getImageData(溜まった描画コマンドの同期ラスタ化を含む)+ 量子化 + putImageData + 転写。
- `--stages` は描画段階ごとに 1×1 の getImageData で強制ラスタ化して `stage:<層>` を出す(バッチ化が崩れるので合計は少し重くなる)。「どの層が重いか」はこれで見る。
- `present` の大半はラスタ化なので「present = 量子化」と読まない。量子化単体は `scripts/dumpframe.mjs` → `scripts/quantbench.ts` で同じ画素を使って比べる。
- 前後比較は同じ機械・同じ引数で 2 回ずつ、計測中に他の処理を走らせない(max に 500 ms 級の外れ値が乗る)。最初の 1 回の 33 ms / render max 数百 ms は読み込み直後の過渡(Vite の初回変換とチャンク焼き込み)で無視してよい。

## 層ごとの重さ(p50、PR #6 後)

| 層 | ms | 備考 |
|---|---|---|
| sky | 0.4 | 空のフィル(色キーで作業キャンバスに焼き込み) |
| background | 0.4〜0.6 | パララックス遠景の帯 |
| megastructure | 1.0〜1.4 | 塔を焼き込みキャンバスに貼る(PR #6 前は 4.6〜5.6) |
| chunks | 0.4 | 焼き込みチャンクの drawImage |
| player | 0.3 | |
| lighting | 1〜2 | 半解像度の暗幕・光。`lighter` の楕円パスは矩形の数倍遅い |
| post | 0.3 | グレイン(3 枚巡回)とビネット |
| present | 2.5〜4 | 読み戻し 0.2(alpha:false)、量子化 2〜3(キャッシュ 2^18)、転写 0.1 |

開始地点の render p50 は約 7〜8 ms、歩行で約 9〜10 ms。

## 入れた対策(経緯)

- PR #1: チャンクを CPU キャンバスに焼き込み、先読みは 8 行の帯に分けて数フレームに分散。クレーターはスクラッチ経由で部分再焼き込み。
- PR #5: 主バッファ `alpha:false`(読み戻し 1.5 → 0.2 ms)、量子化キャッシュ 2^16 → 2^18(グレインでキーが 3 倍になり溢れていた)、ミス時は整数距離。`--stages` 計測器。
- PR #6: 超構造の塔を (spec, 見かけ幅, 環境色, かすみ) キーの焼き込みキャンバスに一度だけ描き、毎フレームは可視帯だけ drawImage。縁が内部 1 px に整数スナップする。

## 新しい描画を足すときの制約

- 平坦な色・少ない色数・`lighter` の画素数最小で設計する(アルファを刻んだ帯、矩形の階段)。
- 毎フレーム描き直さず、既存の焼き込み(チャンク、塔、空のフィル)か半解像度の Lighting overlay に相乗りする。新しい描画パスを足さない。
- 色数を増やすと量子化キャッシュのミスが増えて present が伸びる。グレインのような毎フレーム変わる摂動は特に効く。
- 焼き込みのキーに入れる値(環境色など)は歩行中に変わらないものにする。変わる値をキーにすると歩くたびに再焼き込みが走る。
- 追加前後で上の 3 場面を測り、render p50 と該当する stage の差を PR に書く。
